## Description

## Summary

Makes the email-assistant's "show me my high-priority / needs-reply emails" response **one integrated, interactive list** instead of a prose table + two detached cards over the same emails.

### Before
The list tools (`query_inbox`, `get_important_emails`, `find_needs_reply`, `search_emails`, `find_urgent`) return plain text; the model reprints it as a **markdown table** (inert), and the frontend **separately** renders one tool-result card per tool → the same emails shown twice, in 2–3 places.

### After
- All list-tool results **merge into ONE card**, deduped by email id, with **provenance chips** ("Important", "Needs reply", …) on rows surfaced by multiple tools.
- Each row: **open** in the reading pane, **archive**, **mark read** (already existed) + **Categorize** (new — inline label picker → `PATCH /email/messages/{id}` via `updateEmailLabels`).
- The agent instructions now tell the model to give a **short prose summary** and not reprint the table, so the card *is* the list.

## Scope

Frontend + a prompt tweak — **no backend or schema change** (the "consolidate + integrate" option, over a full structured-data rebuild).

- `workbench/control_plane/src/components/email/EmailToolCards.tsx` — merge loop, `mergeListRows`, provenance chips, per-row Categorize.
- `apps/agent-email-assistant/instructions.md` — "presenting a list of emails" guidance.
