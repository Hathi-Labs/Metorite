## Summary

Continues BO-7 (sandbox hardening) into the piece the earlier cheap-wins pass (#251) and the dep-install RCE fix (#252) deferred: Copilot-SDK-shaped agent execution (`code_task`) still ran fully in-process on the host. This containerizes it.

**Core mechanism**: the Copilot SDK has a native TCP JSON-RPC transport (`copilot/client.py`'s `cli_url`). Instead of porting the whole SDK + a task driver into a container (as the existing `acb-mutation-runner` sandbox does), `Dockerfile.copilot-sandbox` containerizes *only* the `copilot` CLI binary as a TCP server. All host-side orchestration — `CommandCenterCopilotAgent`, event streaming, permission handling — is unchanged; it just connects to a socket instead of spawning a local subprocess. No credentials are baked into the image: `code_task` is BYOK-only, and BYOK travels in the `create_session` RPC payload, not container env (empirically verified the CLI boots and listens with no auth token present at all).

- `orchestrator/copilot_sandbox.py`: lifecycle module — `spawn_copilot_sandbox` reuses the mutation-runner's hardening (`--cap-drop ALL --cap-add DAC_OVERRIDE --security-opt no-new-privileges` + memory/cpu/pids limits), publishes to loopback on an ephemeral port, polls TCP readiness, and returns `None` (never raises) on any failure so callers always have a clean fallback. `get_or_spawn_sticky` adds per-thread container reuse for the App Workshop app-builder's interactive chat path — scoped but **not yet wired** (would need a fresh container every turn without it, regressing latency).
- Wired into `code_session.py` behind a new `copilot_sandbox_scope` setting (comma-separated, default empty = fully off, zero behavior change).
- `permission_policy._workspace_root()` now prefers a `permission_check_root` context override so containment checks compare against the container's mount path, not the host path — without it, containerizing would make every in-workspace write look out-of-bounds.
- Gateway startup sweeps orphaned `cc-copilot-*` containers left by a prior crash.
