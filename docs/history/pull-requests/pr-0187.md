## Description

## What

The last Dashboard v2 item: an **optional single AI sentence** orienting the day — "2 urgent: Ada's invoice, the contract." — atop the mailbox dashboard and the emailed digest.

**Off by default.** It costs a model call each time the digest is built, so it only runs when the user turns it on (Dashboard → Configure → "AI morning brief").

## How

Built from the sections the digest already computes (top needs-reply threads + due commitments), so it's **one `tier-fast` call and no extra query**. Best-effort throughout — flag off, nothing pressing, or a model error all return `""` and the line is simply omitted; failures roll the session back (the same transaction-poisoning guard the rest of the digest uses after the #148 incident).

- **mig 96** — `email_assistant_settings.morning_brief_enabled boolean default false` (idempotent `ADD COLUMN IF NOT EXISTS`; next free number after 95).
- `_digest_brief()` gated on the flag, folded into `_generate_digest` and both renderers, so it appears on the dashboard (`full` projection) *and* the emailed brief.
- Settings toggle in `DigestSettingsDialog` (with the cost stated); dashboard renders the line in a subtle Sparkles card when present.
