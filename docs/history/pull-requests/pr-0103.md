## Description

Caught while preparing to run the #102 repair against the live mailbox — before running it, not after.

The retry selected **every** `FAILED` row for the account. But the commonest cause of these failures is the provider racing us, and the commonest form of that is the user **deleting or junking** the message: **92 of the 138 live failures ended in `trash`**.

Replaying such a row's `MOVE_FOLDER` would have moved the message *out* of Deleted Items and into its category folder — undoing a deletion, in bulk, with no prompt. Exactly the kind of unrecoverable surprise the action-skip list was written to prevent, missed on the selection side.

Disposed folders are now excluded from the selection. Those rows stay `FAILED` and visible rather than being silently 'fixed' into resurrection.

1 new test. Repairs are for mail the user still has.
