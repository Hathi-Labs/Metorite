## Description

A **$0, CPU-only, self-hosted** path to named speakers — the "try sherpa, roll back to Deepgram if it doesn't work" experiment. Merging this **provisions + enables it on the VPS** as a flag-gated trial.

## Proven end-to-end before shipping
Tested in a CPU sandbox against the **real** models on a real 4-speaker sample:
- **Peak RSS ~162 MB** (not the ~500 MB I'd feared) → comfortably fits the 4 GB box; **OOM risk is effectively off the table.**
- **~8.6× real-time** (a 1-hour meeting diarizes in ~7 min, batch).
- **Threshold 0.7 recovers the correct speaker count** where 0.5 over-split (6 vs the true 4) — so 0.7 is the default (env-tunable via `SHERPA_DIAR_THRESHOLD`). Uses the **int8** segmentation model for size/speed.

## What it does
- `packages/acb_stt/acb_stt/local_diarization.py`: additive post-process — when `NOTES_LOCAL_DIARIZATION=1`, models present, and the STT result has no speakers (Whisper): decode via ffmpeg → sherpa-onnx (pyannote seg-3.0 int8 + CAM++ embeddings + clustering) → merge each segment onto its max-overlap speaker turn, labelled `S1/S2/…` (same as Deepgram, so the rename UI just works). Heavy work in `asyncio.to_thread`.
- Wired into `run_transcription` (guarded, no-op by default).
- **`deploy.yml` [trial] block** (idempotent): installs the optional extra, downloads the two ONNX models (~6 MB + ~27 MB, URLs verified through the proxy), and upserts the flag + model paths + threshold into `.env`. Gated on `LOCAL_DIAR=1`.

## How to try it (after merge → deploy)
Make sure the STT tier is a **Whisper** model (Deepgram already diarizes, so sherpa is skipped for it), then **record/upload a short clip** or hit **Re-transcribe** on an existing meeting → speakers should appear, free.

## Rollback (your "fall back to Deepgram" plan)
- Flip `LOCAL_DIAR=0` in `deploy.yml` (or `NOTES_LOCAL_DIARIZATION=0` in `.env`) + redeploy, **or** just select a `deepgram/*` STT model.
- Fail-safe throughout: package/models/ffmpeg absent, decode/inference error, OOM → silently returns the speaker-less transcript; never fails a run.
