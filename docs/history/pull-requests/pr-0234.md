## Description

## What & why

The WhatsApp vertical was desktop-only: a fixed left sub-nav column and a three-pane inbox (spine → chat list → conversation) that overflowed a phone viewport. This brings it in line with the shell's other apps (email, tasks), which collapse to a single mobile pane and lean on the global bottom nav. Layout decisions come from the existing `useViewMode()` hook, so nothing changes on desktop.

## Changes

- **Shell (`layout.tsx`)** — on mobile the persistent left column becomes a compact, horizontally scrollable tab strip (Inbox · Pulse · Categories · Replies · Rules · Numbers + Connect) above the content; desktop keeps the left column unchanged.
- **Inbox (`page.tsx`)** — a mobile single-pane drill-down:
  - The three desktop panes collapse to one; the triage spine becomes horizontal stream pills with a tappable number header (`MobileAccountBar`, which opens *downward* instead of the desktop switcher's upward menu).
  - Tapping a chat drills into a full-width conversation with a back button; the Details panel becomes a full-screen overlay instead of a side rail.
  - `Conversation` gains `isMobile`/`onBack` props and hides its verbose window badge and button text labels on narrow screens so the header never overflows.
- **Sub-app + connect pages** — `p-4` on mobile (`p-6` at `md`); the policy/rules tables scroll horizontally instead of squishing; the saved-reply form stacks its inputs.
