## WS-32 — organisation identity

- **OI-1** — logo upload. `gateway/image_probe.py` identifies PNG/JPEG/WebP from **magic bytes**, never the caller's declared MIME type, and the stored `data:` URI is rebuilt from what the server derived. SVG and PDF are named in the rejection message. Bounds: 128 KB, 32–2048 px per edge, 0.5–8.0 aspect.
- **OI-3a** — first-paint branding. The shell used to render *our* mark and swap to the customer's ~900 ms later, which inverts the feature. Now cached and revalidated behind the paint. `localStorage` is not a trust boundary, so a cache hit is validated exactly like a network body.

## What is NOT verified, stated plainly

- **`e2e/org-branding.spec.ts` is entirely `test.fixme`.** The app does not hydrate under Playwright in dev — measured: zero `/api/**` requests, a failing HMR handshake. An earlier run reported **9 of 18 passing** and every one of those was a fallback or outage case, which an un-hydrated page renders anyway; they would pass with the client bundle deleted. The partial pass was the dangerous part, so the file asserts nothing rather than asserting that.
- **OI-2 (tenant-scoped `org_settings`) is not done and is blocked on MT-1b.** `org_settings` has a single-column PK on `key`, so branding is org-wide today. This is a hard prerequisite for customer #2, and the source comment that claimed tenancy "comes free here" was false and has been corrected in place.
- `infra/platform/*.sql` is **not** applied by the deploy — the Control Plane database is Supabase (D34) and remains owner-gated, so `platform_api` ships inert.

## Fences added

`_required_permissions` reads the `require_permission` closure and asserts `admin:settings:manage` gates the branding writes — the 30 tests before it called handlers directly and would have passed with the gate deleted. It went red first, then was proved by mutation. Same treatment for the `captionClipped` probe, which originally matched the outer flex container and so could not fail in the case it was written for.

The BFF body bound was `content-length` only — a header a chunked-encoding caller simply declines to send, which is the attack its own comment claimed it stopped. It now bounds the **stream**.
