## Phase 3 · item 3.1 (depends on 2.5)

The long-requested **"draft in my voice"**, now cheap. `_fetch_sent_fewshot` embeds what's being replied to and cosine-matches the account's **own Sent mail** (any recipient) via `email_embeddings`, injecting the top-3 quote-stripped bodies into the reply prompt as a **voice block**.

Distinct from `sender_examples` (past replies to *this* sender → the relationship); the few-shot shows the **register** for this *kind* of message.

Wired into the single `_build_reply_context`, so every drafting entry point (`/draft-reply`, "Draft with AI", and the rule path via 3.8) gets it. The current thread is excluded so a reply can't echo itself.

### Safe + dormant until enabled
`embed_query` returns `None` when `email_semantic_search_enabled` is off (no LLM call, no DB query), so this adds **zero cost and no examples** until embeddings are populated — matching the 2.5 dependency.

⚠️ **Enablement is a separate decision:** turning on `email_semantic_search_enabled` starts a **token-costing background embedding sweep on the live mailbox**. I did not flip it here. Say the word and I'll enable it (one-line default change) and watch the sweep populate embeddings so this activates — then verify a draft actually picks up the voice examples on the live account.
