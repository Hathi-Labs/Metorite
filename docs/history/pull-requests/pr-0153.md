## Description

Re-centers the task-manager calendar on the daily loop — **Plan · Do · Review** — so it becomes the primary surface for focusing, completing tasks, and planning the day. Implements phases F0 + F1 of the new `ai-company-brain/specs/calendar_focus_os.md` spec, woven into the existing `CalendarView`/store/planner with **no backend or schema changes**.

## Spec & mockups
- `ai-company-brain/specs/calendar_focus_os.md` — evaluation of the shipped calendar, method-by-method mapping (GTD, timeboxing, Pomodoro, breaks, 2-minute rule, meditation, planning, task breakdown, 80/20, batching, outcome-focus), a cross-check against the "100 productivity tips" list, an ecosystem-fit table, and phasing.
- `ai-company-brain/specs/mockups/calendar_focus_os.html` — six annotated UI mockups.

## Features
- **Leverage lens + meter (80/20):** leveraged/important blocks render gold on the grid and rail; each block shows its project-outcome ribbon; a leverage meter (booked leveraged hours + %) joins the capacity meter.
- **★ One Thing:** per-day commit via star toggles on blocks/rail; strongest gold treatment, sorted first, counted as leveraged; "Plan my day" instructs the AI planner (via the existing `energy_note` seam) to protect it in the first peak-energy window.
- **Gap Filler:** the tap-a-slot / mobile sheet measures free minutes until the next block — the 2-minute pile first (one-tap **Done**, never scheduled), then fits-the-gap tasks ranked by the priority matrix; longer tasks visible but muted. Scheduling into the live moment drops straight into Focus Mode; the idle Now-bar invites filling the gap.
- **Startup ritual:** once-a-day banner → Breathe (60s, skippable) → Review carry-forwards (one-tap rollover) + due-soon → Commit the One Thing (seeded from last night) → AI plan. Completion streak tracked.
- **Shutdown:** end-of-day review gains the leverage-ratio tile, One-Thing verdict, seed-tomorrow picks (≤3, pre-loading the next startup ritual), and an explicit "Close the day".
- **Focus Mode** (`components/FocusMode.tsx`): full-screen Do room — Pomodoro 25/5 · 50/10 · Flow ring, outcome line, subtask checklist ticked in place, pause / done-early / +15 min (flexible rest of day reflows), typed break transitions, next-block footer; stamps the existing `actualStart`/`actualEnd` so planned-vs-actual + learned estimates keep working. The global `C` capture palette opens above the room (capture-in-focus).

Per-day state (One Thing, seeds, ritual stamps, timer prefs) lives in localStorage (`lib/focusPrefs.ts`); server persistence is a noted follow-up.
