## Description

## What & why

The triage stream list still read as its own component next to the rest of the control plane: a `rounded-lg` row with a `border-l-2` primary accent rail, bold active text, and a plain cyan count that rendered a stray `·` at zero. Email/tasks sidebar items do none of that.

## Change

Rebuilt each stream row on the email folder-button pattern:
- `rounded-md` row (was `rounded-lg` + `border-l-2` accent rail)
- Active = `bg-primary/15 text-primary` with **no** accent rail
- Idle = `text-muted-foreground` with a muted hover
- Count → a `rounded-full` **pill badge** (`bg-primary text-primary-foreground` active, `bg-secondary text-muted-foreground` idle), **hidden when zero** (so "Snoozed" no longer shows a stray `·`)

The spine now looks identical to email's folder list / the rest of the sidebar nav.
