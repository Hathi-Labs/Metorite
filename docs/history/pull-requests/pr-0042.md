## Description

Reworks the founder prioritization matrix per your revised formula and the key reframe: **delegate / eliminate / schedule are suggestions, never a status the task lives in.**

## Revised formula (your 1→8 sequence)
The 8 cells keep the same input→cell mapping, but adopt your revised order + labels. The new sequence **interleaves** leveraged and non-leveraged cells by true priority:

| # | Inputs | Label | Nudge |

| 1 | Lev+Imp+Urg | Founder Fire / Schedule 🔥 | *do* |

## Suggestion, not status
- The delegate/schedule/eliminate nudge is now a **competing, dismissible badge on the task card** (`SuggestionBadge`) — it never changes the task's status; the × dismisses it ("keep mine").
- **Removed** the sidebar "To delegate" / "To schedule" buckets, the store's `selectedMode`/`selectMode` drill-down, and `modeSuggestionCounts`.
- The **Priority view** is now a flat **ranked list** (by matrix rank, cell badge per card) instead of status-like cell buckets.
- One-badge-per-card: the Priority/ranked view shows the cell badge; every other view shows the competing action nudge.
