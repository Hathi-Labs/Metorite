## Description

Reported from a screenshot. Three defects, all in one dialog.

## 1. The sender was truncated

```
From anil.pradhan@haigcapital.com → Cold E…
From notification@sign.plus → Notification · ab…
```

A single flex row with `truncate`. An address + a rule name + a reach count does not fit one line in a dialog, so it cut off exactly what you need to judge the pattern. Now two rows — chips, reach and actions on top; the pattern gets full width below and wraps.

## 2. "arewaiting"

> **21 patterns learned by the assistant** arewaiting for you.

The sentence was assembled from word fragments split across source lines around `{expressions}`, so its spacing depended on JSX whitespace collapsing.

This is the **second** time in this codebase — the same fix went into `BulkUnsubscribeView`'s "emails match" line last week, with a comment explaining why. I wrote that comment and then did the same thing here. Now built from explicit strings.

## 3. The dialog described the wrong thing

> Senders the assistant learned to match (or skip) for a rule, **from your Fix corrections.**

Every pattern on the live account is `source='AI'`. Not one came from Fix. The subtitle told you these were your own past decisions — which is precisely the belief that let 45 unreviewed machine inferences accumulate without anyone questioning them. It now says what they actually are and why the Cleaner waits for confirmation.
