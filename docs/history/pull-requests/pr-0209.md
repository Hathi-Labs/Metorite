## Description

Two note-taker features on the same branch.

## 1 · Provenance you can touch — tap notes back to the transcript

Every claim is verifiable in one tap: click a decision or an action item and land on the exact transcript moment it came from, with the audio cued (reuses the Ask panel's `jumpToSegment`).

- **Action items** render their source moments as tappable timecode chips (`▸ 2:14`). Pure UI — `segment_ids` already flowed through the API, **no backend change**.
- **Decisions** in the Summary tab get a "tap a timestamp to hear it in context" card, from the `refs` the generator already emits. The one backend touch: `MeetingDetail` passes through the already-stored `summary_json` (`core.py`/`meetings.py`; `types.ts` gains `SummaryJson`).
- Display-only: `summary_md` and the follow-up email drafted from it are untouched.

## 2 · Recording Dock — "the app follows you" (spec §5.2)

An in-progress recording now **survives navigation**. Previously the `MeetingRecorder` lived in a `useRef` inside `/notes/session/[id]` and its unmount effect called `cancel()` — so leaving the studio screen **dropped the recording** (mic released, unacked chunks discarded).

- **`notes/lib/recordingStore.ts`** — a module-level Zustand store owns the single `MeetingRecorder` + a non-reactive VU buffer (per-frame levels kept out of React state so they don't thrash renders). `start`/`pause`/`resume`/`stop`/`cancel`; guards a second concurrent session.
- **`notes/components/RecordingDock.tsx`** — mounted once in `AppShell` (sibling of the router outlet, mirroring the tasks Focus-timer dock), it shows whenever a recording is live and you're **not** on its studio screen: timer + REC/paused dot + pause/stop, tap to return. Navigation itself is the minimize/expand.
- **`session/[id]/page.tsx`** — now a *view* onto the store; the recording-killing unmount `cancel()` is gone. Handles the "another recording is in progress" case and adds an explicit **Discard** control.
- **Mobile menu-bar accommodation** (as requested): the dock clears the fixed bottom nav (`3.5rem + safe-area`) and **stacks above the Focus pill** when both are up (reads `useTaskStore`); the Focus dock's own offset was reconciled `3rem → 3.5rem` to match `.pb-nav` so **neither dock is clipped by the bar**.
