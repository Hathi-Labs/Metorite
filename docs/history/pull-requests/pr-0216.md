## Description

On a phone, the meeting-detail header's "Transcribed by …" subtitle wasn't truncated, so it wrapped to several lines and **collided with the Follow-up / Regenerate buttons** — the long transcript-source string (e.g. `groq/whisper-large-v3+sherpa-diar`) made it worse, and the full-width text buttons squeezed the title to `Not…`.

**Fix:**
- Subtitle now **truncates** (single line + ellipsis); the title block flexes (`flex-1 min-w-0`) so it takes the space and shrinks cleanly.
- Action buttons are `shrink-0` and **icon-only on mobile** (Follow-up / Regenerate labels hidden `< sm`, `aria-label`/`title` kept for a11y); full labels return on desktop.

Frontend-only; `tsc` clean. (The lone eslint `set-state-in-effect` finding is pre-existing on the mount loader, unrelated.)
