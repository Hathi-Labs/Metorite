## Description

Adds `ai-company-brain/specs/calendar_ai_review.md` — a comprehensive audit of the calendar application, its integration with the GTD task manager, and every AI surface in the stack — plus the two audit findings that could be fixed frontend-only.

## The review covers
- **Integration architecture** (§1): the calendar as a view over the same `gtd_items` rows — one data model, one priority brain (`priority.ts` mirrored in the planner fallback), one capture pipeline, provider-sync-safe scheduling overlay.
- **AI inventory with per-surface verdicts** (§2): day planner (LLM judgment / deterministic geometry split), learned-estimate padding, replan/rollover, chat agent + persona, clarify engine, atomize, enrich/suggest-title/backfill, project planning, email capture. Prompt hygiene is consistently strong (DATA-quoting of third-party text, id whitelisting, strict-JSON + deterministic fallbacks).
- **"Can AI manage my day?"** (§3): via the UI — yes, well. Via chat — partially: the agent can read the grid and move single blocks but **cannot call the planner**, must hand-place blocks, and (before this PR) couldn't see fixed-vs-flexible blocks or the ★ One Thing.
- **Ranked recommendations** (§4): persist Focus-OS day state server-side (unblocks everything); register `gtd_plan_day`/`gtd_replan_rest`/`gtd_rollover` as chat tools (proposal → confirm → apply); close context gaps (`gtd_list_schedule` fixed/done markers, project outcome in the planner brief); new chat capabilities (morning digest, interruption triage, deadline-risk radar, NL timeboxing, conversational shutdown/weekly review, batch suggestions); chat-side undo parity.

## Fixes shipped
- **Replan modal**: the energy-note input is now plan-mode only — `/calendar/replan` is a deterministic repack that ignores the note, so showing the input there was misleading.
- **Chat persona** (`taskAssistantPersona.ts`): 🔒 markers on fixed blocks + an explicit never-move rule, ★ One Thing injection (client-side read) with a protect instruction, energy windows, done-today tally, and propose-before-apply guidance for multi-block reorganizations.
