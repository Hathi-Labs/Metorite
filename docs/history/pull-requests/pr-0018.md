## Description

Keeps CommandCenter developable by coding agents as it grows. Three layers, grandfather-and-ratchet throughout (current code passes; pressure only on new debt). Full plan + baseline: [`dev_velocity_tooling_2026-07.md`](ai-company-brain/specs/dev_velocity_tooling_2026-07.md).

## Baseline measured (2026-07-04)
Repo-wide avg cyclomatic complexity is healthy (~6.9, grade B) — the problem is a *tail*: `executor.run_agent_stream` is **cc 223** in a **5,020-line** file; 33 files over 800 LOC. That tail is what makes files un-editable by agents.

## Commits

**1. `chore(ci)` — complexity + correctness gates**
- `xenon` complexity ceiling **blocking** (grandfathered: `abs=F` covers cc=223, `avg=B` is the ratchet — a PR worsening the average, or adding a function worse than today's worst, fails).
- `ruff` correctness **blocking** (F821/F601/F602/F502/F7/B006 — catches real bugs).
- `ruff C901` + full `ruff` + `mypy strict` as **report-only** dashboards (the ~1.3k style backlog is ratcheted down by hand — see below).
- `.pre-commit-config.yaml` (was a dep with no config) — diff-scoped, no big-bang reformat.

**2. `fix:` — three latent bugs the new correctness gate immediately found**
- `imap.py` `get_message` called a nonexistent parser → NameError on every IMAP single-message fetch.
- `runner.py` AI-draft hydration referenced an undefined `account_user` → NameError on that branch.
- `acb_llm/client.py` duplicate `OPENROUTER_API_KEY` dict key → deduped.

**3. `feat(dev-velocity)` — code-graph MCP + weekly code-health review**
- **L2:** `.mcp.json` commits **CodeGraph** (MIT, local SQLite+tree-sitter, Python+TS) so any coding agent in-repo gets symbol/call-graph navigation. Verified working: indexed 615 files / 15,050 nodes / 51,164 edges.
- **L3:** `scripts/codebase_health.py` (radon-based, read-only measurement) + `codebase-health.yml` (weekly issue) + per-PR `--diff` report + `skills/maintenance/codebase_health_audit/` (the flag-and-propose refactor skill). Runs as GitHub Actions, not an in-app agent (the repo deliberately has no in-app cron).

## Reviewer notes / caveats
- **No blanket `ruff --fix`.** A repo-wide auto-fix was attempted and reverted — it silently deletes this repo's intentional re-exports / side-effecting imports (documented as the "Auto-fix hazard" in the spec). The style backlog is paid down by hand.
- **CodeGraph needs a one-time per-dev install** (`npm i -g @colbymchenry/codegraph && codegraph init`) — a global binary; review before installing. The committed config is inert until then; the local index is gitignored.
