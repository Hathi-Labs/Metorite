## Description

## Summary

Makes **Reply All** the default reply action across the email UI — Rapid Inbox, EmailDetail (mobile), toolbar (desktop), and ConversationView.

## Changes

### RapidInboxView (`InlineReply`)
- Defaults to **reply-all** mode with a segmented Reply/Reply-All toggle
- Auto-computes recipients: extracts all addresses from the email (To + CC) minus the user's own email
- CC field is visible when reply-all is active
- **AiAssistBar** wired in under the composer for improving existing drafts

### EmailDetail
- Mobile toolbar: Reply All is now the first/default option
- Composer header: inline reply/reply-all toggle via `switchReplyMode()` that preserves draft text

### EmailToolbar
- Desktop: Reply All button is now the leftmost action

### ConversationView
- Thread card: Reply All button is now the leftmost action
- Shortcuts bar: `r` key label updated to 'Reply All'
