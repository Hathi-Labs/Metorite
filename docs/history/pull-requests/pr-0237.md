## Description

## What & why

The WhatsApp app looked subtly "off" next to email/tasks: it used hardcoded **emerald** accents throughout, while the rest of the control plane draws from the theme tokens — **`primary`** (cyan) for chrome/accents and the **`success`** token for green status. This sweeps all 36 emerald usages onto those tokens and adopts the shared active-nav treatment, so WhatsApp matches email/tasks/chat.

## Changes

- **Accent / chrome → `primary`**: app + section-header icons, connect-card hover, the pairing step indicator, the "Fastest"/"Default" badges, the "Connect another number" link, the outgoing message bubble, empty-state icons, and the **Send** button (`bg-primary text-primary-foreground`, matching chat's send).
- **Genuine status-green → `success`**: `● live`, "session open", "Linked!", "Verified with Meta", the connected/done confirmations, and the copied/selected checks — the same `success` token agents/tasks use for live + success.
- **Active nav items → `bg-primary/15 text-primary`**: the left-column tabs, the mobile tab strip, the triage-stream spine, and the mobile stream pills, replacing the ad-hoc `bg-muted` highlight (this is the email/tasks sidebar convention).

## Left intentionally off-palette

- The QR code's white backing (a QR must scan in any theme).
- The Meta-mandated `#1877F2` "Continue with Facebook" button.
- White initials on per-account colored avatars (same as email/tasks).
