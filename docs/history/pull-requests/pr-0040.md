## Description

Two stacked task-manager features (this branch carries both commits).

## 1. Email → task capture popup + delete/undo/archive overhaul (`a9319b8`)
- **Add to Tasks** is now a clarify-before-capture popup: subject-derived default title, "Enhance with AI" (reads the full email + thread), similar-task warnings; writes only on confirm. Backend split into `/preview` · `/enhance` · `/create`.
- **Delete** is now soft (tombstone, migration 67) → lossless Undo; the real ClickUp DELETE fires only after the undo window (`provider.delete_task`, broker-gated). "Are you sure?" for ClickUp/clarified tasks. Undo toast lifted to page-level (shows in every view).
- **Done view**: completed tasks stay there until archived (they were vanishing).
- **Archive**: local overlay for local + ClickUp tasks; bulk archive/restore/delete via multi-select.

## 2. Founder prioritization matrix — Priority + Engage views (`d01368b`)
- Two manual flags (**important** = downside, **leveraged** = 100x upside) + **urgency derived** from the due date (overdue or ≤ configurable window, default 48h) → compute the user's **8-cell Notion matrix** (Founder Fire → Eliminate). The cell is a projection, never stored. Shared engine `lib/priority.ts` + byte-parity `priority.py`, unit-tested for all 8 cells.
- **Clarify + detail** get a 3-flag Weight control, AI-prefilled (heuristic + LLM), you confirm. Local overlay, never back-synced.
- **Toolbar**: Group-by (context / priority / action-mode / energy / none) + Priority/Urgency sort.
- **My Next Actions**: dismissible **To delegate** / **To schedule** hint buckets (suggested, never auto-moved; `keptMine` dismisses).
- **Priority view** (8-cell map, with an untagged-triage hint) + **Engage view** (energy-first "what can I do right now", matrix-ranked).
- One-badge-per-lens rule keeps cards uncluttered. Migration 68 adds the flags + `urgent_window_hours` setting.
