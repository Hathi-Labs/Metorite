## Description

## Why

`design.md` (~16 KB) was pasted **inline into every Copilot agent's system prompt, every turn** — and never reached native MAF agents at all. This makes it on-demand: a tool agents reach for only when they actually need the full design language (a full-page report or bespoke custom HTML), exactly as requested.

## What

- **New tool `load_design_system()`** (`acb_skills/design_tools.py`) — returns the design system (palette tokens, typography, spacing, motion, dark/light, the `cc-report` block kit). On the core tool floor for **both** runtimes, read-only.
- **Removed the inline `_design_md_section()` injection.** The addendum now carries only a cheap pointer (`### Design language — load on demand`). Net effect: ~16 KB off every Copilot prompt, and MAF agents finally have design access on demand.
- **Front matter on `design.md`** (`name`, `when_to_use`, `summary`) documents the trigger; the tool strips it and returns the body.
- Dropped the now-unused `_load_design_md` / `_design_md_section` from the orchestrator.

## When agents load it

Only for the heavy cases — a full-page HTML/Markdown **report** or a bespoke custom-HTML `emit_generative_ui` card. Named templates stay on-brand by construction (no call needed), and the `--cc-*` tokens named in the proactive UI directive already cover simple custom HTML. So the common paths stay cheap and the heavy design reference loads on demand.
