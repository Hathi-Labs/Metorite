## Description

## What & why

On mobile the WhatsApp sub-navigation sat in an in-page **top strip** (section tabs) plus a row of triage-stream pills. Every other app instead drives its mobile sub-nav from the **shell's bottom bar** + a **slide-up drawer** (email: Menu/Inbox/Automation/AI Chat; tasks: Menu/Inbox/Lists/Capture/Assistant). This rebuilds WhatsApp on that same pattern.

## Changes

- **`AppShell` (`MobileBottomNavInner`)** — added WhatsApp context tabs: **Triage** (inbox only) and **Sections** (every `/whatsapp` page), each dispatching a `cc-mobile-nav` event, exactly like the existing email/tasks/notes tabs.
- **`layout.tsx`** — removed the mobile top tab strip. The section list (Inbox · Pulse · Categories · Replies · Rules · Numbers + Connect) now renders inside the bottom-nav **drawer**, opened on `wa-sections`. Desktop keeps its left column unchanged.
- **Inbox (`page.tsx`)** — removed the inline stream pills and the `MobileAccountBar`. The triage streams (+ number switch when multi-account) now live in a **drawer** opened by the **Triage** tab or by tapping the slim list header (active stream, its count, and the live number). Selecting a stream/number closes the drawer and updates the list.

Desktop is untouched — all changes are gated on `useViewMode().isMobile` / the mobile bottom bar.
