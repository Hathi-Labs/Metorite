## Summary

Two user-reported email-app fixes:

### 1. AI-drafted emails now always open with a salutation
Drafts sometimes jumped straight into the body with no greeting line ("Dear <name>," / "Hi <name>,"), reading abrupt and informal. The reply drafter's prompt asked for a greeting but nothing enforced it, and two paths (compose assist, notes meeting recap) never asked at all.

- **`_ensure_salutation` backstop** (`drafting.py`): if a draft's first line isn't a greeting (recognised opener word, or a short comma/colon-terminated line so other-language greetings are never doubled), prepend `Dear <first name>,` — honorific-aware (`Dear Dr. Smith,`) — or `Hello,` when no name is known. Applied to every reply draft (`/draft-reply`, compose "Draft with AI", rule REPLY/DRAFT_EMAIL actions, follow-up nudges) and to fresh compose-assist drafts; never when improving the owner's own text, and never to the NO_DRAFT sentinel.
- Compose-assist drafting prompt now demands a greeting line, matching the reply drafter's rule.
- Notes meeting-recap prompt now opens with a "Hi all,"-style greeting.
- Email-assistant agent instructions: every reply opens with a salutation addressing the recipient by name.

### 2. Mobile bottom nav bar no longer covers page content
The fixed bottom nav is `pb-safe` padded, so its real height is its content (~3.5rem) **plus** the device safe-area inset — but the shell only reserved `pb-14` under pages. On iPhones the bottom ~30px of every page hid under the bar (the reply composer's attach / AI files / Pop out / Discard / send row was half cut off).

- New `.pb-nav` utility (`calc(3.5rem + env(safe-area-inset-bottom))`); the mobile shell's `<main>` uses it instead of `pb-14` — fixes the email app and every other page rendered in the shell.
- Pop-out `ComposePanel`: window height capped to the viewport with the fields scrolling inside, so the Send/Discard footer always stays on screen (matches the automation modal's existing pattern).
- Email task-capture + undo-send toasts sit above the nav bar on mobile instead of overlapping it.
