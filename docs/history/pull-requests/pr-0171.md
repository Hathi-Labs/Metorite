## Description

The HTML quote splitter only recognised marker ids/classes (#divRplyFwdMsg,
#appendonsend, .gmail_quote, cite blockquotes). Outlook DESKTOP (the Word
renderer — what most corporate/academic correspondents use) emits none of
those: its reply header is a bare short block "From: ... Sent: ... To: ...
Subject: ...", so RE: RE: chains rendered fully expanded instead of behind
the ... toggle.

Adds the same text heuristic the plain-text splitter already uses as an HTML
boundary detector (header block / "On ... wrote:" / "-- Original Message --"),
with a short-text cap so whole-chain wrapper divs never match, preferring the
bordered wrapper so the divider collapses with the quote. The empty-main guard
still prevents hiding a body that IS just a forward. tsc clean.
