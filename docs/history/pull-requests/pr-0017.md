## Description

Six-feature batch on the GTD task manager's clarify + capture stages (spec: `ai-company-brain/specs/task_manager_app.md` §9.1 changelog, updated in this PR).

## What's in here

**1. Live delegate list from ClickUp**
- `BaseTaskProvider.list_members` + ClickUp implementation (live `/team` membership)
- `POST /tasks/accounts/{id}/members/refresh`; every `/tasks/sync` also refreshes `schema_cache.members`
- ClarifyPanel pulls fresh members when a SYNCED destination is chosen — people removed on ClickUp drop out of the delegate picker; remaining members are enriched with org-people roles (matched by provider user id / email / name)

**2. Delegate defaults to ClickUp, auto-push**
- WAITING with a Local destination auto-selects the first SYNCED workspace (opt-out by picking Local)
- Clarify decisions that stage a synced item now auto-push to the provider; on failure the item stays `pending` for manual push

**3. Project picker mirrors ClickUp's tree**
- `get_schema` now returns a navigable `hierarchy` (spaces → folders → lists); flat projects keep `space_id`/`folder_id`
- `WorkspaceProjectAccordion` renders nested accordions with search and the AI-suggested project highlighted

**4. Create project in place**
- `provider.create_project` (`POST /space/{id}/list` or `/folder/{id}/list`) via `POST /tasks/accounts/{id}/projects` (owner-checked)
- "+ New project" rows inside each space/folder create the list on ClickUp, upsert `gtd_projects`, refresh the cached hierarchy, and select the new project for the item being clarified

**5. Dense Notion-style inbox list**
- `InboxTable`: Capture · AI-suggests · From (email origin) · Source · Age columns, paperclip counts, hover triage actions
- Cards/list toggle sticky per browser via `useSyncExternalStore` — fixes a hydration mismatch from reading localStorage in a `useState` initializer

**6. Capture attachments (photo / file / link)**
- Migration `52_gtd_attachments.sql` (+ `gtd_items.attachments` JSONB)
- `POST /tasks/attachments` (15 MB cap, executable extensions blocked, sanitized names) + owner-checked serving
- `AttachmentComposer` under the hero capture bar and QuickCapture; chips on cards, table rows, clarify header, item detail

**Proxy hardening** (`/api/tasks/[...path]`): multipart uploads and binary downloads pass through byte-exact; idempotent GETs retry once — stale keep-alive sockets to the gateway intermittently 502'd hydration and silently flipped the store to demo/mock data.
