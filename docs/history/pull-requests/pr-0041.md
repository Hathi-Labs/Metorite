## Description

Fixes two ClickUp integration bugs, both confirmed against live production data.

## 1. Synced tasks all showed in "Backlog"
The Next-Actions board and grouped list grouped tasks by the **local** Kanban stage (`workflowStage`) — which is always null on synced ClickUp rows. So every ClickUp task collapsed into the first column, ignoring its real status. The status data itself was fine end-to-end (pulled, stored as `provider_status`, mapped to `providerStatus`); only the display grouping was wrong.

**Fix:** a unified status axis.
- `statusColumns(localStages, providerStatuses)` — columns are the union of local workflow stages + every connected tool's statuses (de-duped, provider order first).
- `statusColumnForItem(item, columns, first)` — a LOCAL row keys off `workflowStage`, a SYNCED row off `providerStatus`, so both land in their real column.
- Drag-to-refile is now **source-aware**: dropping a synced card sets `providerStatus` (back-syncs to ClickUp); a local card sets `workflowStage`.
- Store exposes `providerStatuses` (from `providerStatusesFrom(accounts)`), refreshed on hydrate + account refresh.
- The old opt-in `stageMode` prop is gone; `ProjectTasksView` keeps its explicit `stages`.

## 2. A clarify-delegate never reached ClickUp
Delegating a task to a teammate via **Clarify** (as opposed to the dedicated Delegate action) set an assignee + synced destination + `sync_state='pending'` but **never pushed** and didn't require a project — so the task stranded local-only (WAITING, empty `provider_task_id`), invisible to the assignee in ClickUp. (Root-caused to one real stranded task in prod.)

**Fix:** `organize_item` now
- refuses a synced delegation with **no project** (400 before any write — fail-closed, so it can't create a stranded row), and
- **auto-pushes** to the tool after commit (parity with `POST /items/{id}/delegate`), via `_maybe_push_delegated` → `_push_pending_item`. A push hiccup is deferred, not fatal to the clarify.
- The Clarify UI gates the Accept button and shows a hint explaining a list is needed to delegate.
