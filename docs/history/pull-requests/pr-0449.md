## What the page actually does

But of **422 elements, zero carry `__reactFiber` or `__reactProps`**, and `localStorage` is entirely empty, so not one mount effect ran. The root is created; the tree is never hydrated.

## I nearly reversed a correct finding on bad evidence

A mid-way probe counted keys starting with `__react`, found 6, saw `window.next` and a DevTools hook, and read that as *"it hydrates — the board is wrong."*

Six was too few for a 422-element shell, so I measured `__reactFiber` specifically: **zero**. A handful of `__reactEvents` on the container is exactly what an *un*-hydrated React root looks like.

Reporting one step earlier would have overwritten a correct finding with a false correction — the fifth of this session, and the only one that would have gone the wrong way.
