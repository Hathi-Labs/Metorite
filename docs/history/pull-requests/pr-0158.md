## Description

Addresses three usability issues found in real use of the calendar:

## Changes

- **Restartable startup ritual** — a "Start day" button now sits in the calendar header (visible until the day is closed). Skipping the morning banner no longer locks you out for the day: reopen the ritual any time to breathe, review carry-forwards, (re-)commit the ★ One Thing, and replan.
- **Unified unscheduled rail** — the separate, non-draggable "Due soon" section duplicated tasks that also appeared below as timeboxable cards. It's now **one list**: deadline pressure is a *property of the card* (amber tint, "⚠ due today / due in Nd" badge, warning-toned Timebox button) plus a sort boost — ★ One Thing first, then soonest deadline, then the priority matrix. Every card drags onto the grid and timeboxes identically.
- **Click a block → open the task card** — previously only the block's title text was clickable. Now a click anywhere on the block body opens the task card; drag still moves, resize still resizes (its trailing click is swallowed), the hover controls and long-press context menu still do their own thing (the × unschedule button was missing a `stopPropagation` and would have also opened the card).
