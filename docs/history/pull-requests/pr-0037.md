## Description

Agent identity in the control plane — two user-facing features plus a small rendering fix, all in the same agent-facing components.

## Display-name (alias)
Editable friendly name for **any** agent (MAF + Copilot SDK, built-in + custom).

- **Backend:** alias stored as one `model_config` `agent_aliases` blob keyed by canonical name (no migration; uniform for static + dynamic). `GET /agent` and `GET /observability/roster` overlay `display_name`; `PATCH /agent/{name}` accepts `display_name` for any agent (built-ins allowed for the alias only — it's a separate overlay, never the built-in code definition).
- **Frontend:** editable field in Agent Settings (shows the friendly name with the canonical slug beneath), resolved `display_name || name` everywhere the name renders — Agents page, chat header/selector/switcher/picker + session-group headers, and observability office/feed/history/drawer.
- Canonical `name` stays the key for runs, avatars, localStorage, dispatch and DB rows; the alias is a pure display overlay.

## Avatar logos
Use an agent's assigned pixel-art avatar as its logo.

- New reusable **`<AgentAvatar>`** renders a circular **face + torso** crop of the existing 124×124 standing sprite (`CHARACTER_LIBRARY` portrait) via an oversized background — **no new images**. `useAgentAvatars()` fetches name→libraryId from `/api/observability/avatars`.
- Shown only when an avatar is assigned; falls back to the existing Lucide icon. Wired into Agents page tiles + detail header and the chat picker/switcher/header.
- Crop framing exposed as props (`zoom`/`focusX`/`focusY`) so it's tunable per surface.

## Fix
Two `…` / `—` escapes were written as JSX text (rendered literally as the raw escape); replaced with the actual glyphs.
