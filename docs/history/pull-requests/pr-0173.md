## Summary

UX pass on the chat page layout and agent identity, per Vijay's direction to make agent characters prominent and de-drab the conversations column.

**Layout**
- Column order is now **conversations | files | documents | chat** — the Files panel moves from the right edge to the left of the documents panel (`ArtifactSidebar` gains a `side` prop that flips its border and collapse-chevron direction; mobile drawer unaffected).
- The **collapsed conversations column now matches the other rails**: reopen icon, conversation-count pill, running-agent pulse dot, vertical `CONVERSATIONS` label (was a bare chevron strip).

**Conversations column polish**
- Primary-styled "+ New conversation" button, client-side search over titles/previews/agents (auto-expands groups while searching).
- Agent avatars on group headers with an emerald ring while that agent is running.
- Items: active accent bar + tinted background, relative timestamps ("2h"), clamped previews, delete revealed on hover.

**Agent identity (the character front-and-center)**
- New shared `BreathingCharacter` component: renders the character-library breathing spritesheet (same loop as the office/avatar picker), falls back to each agent's namesake office character so every first-party agent animates, id-guarded single style injection, respects `prefers-reduced-motion`.
- **New-session picker**: two-column cards — breathing character at full card height on the left, info on the right, descriptions clamped to two lines; modal widened; the default CommandCenter entry gets the orchestrator character.
- **Agent settings side panel**: matching two-column identity header — breathing character left, name/runtime/status badges right.
