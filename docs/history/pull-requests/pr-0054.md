## Description

## Bug

Opening the **Context** view threw `Uncaught Error: Minified React error #185` ("Maximum update depth exceeded") — an infinite render loop, introduced by the columnar-list change (#53).

## Root cause

`readColumnVisibility()` is the `getSnapshot` for `useSyncExternalStore`, but it returned a **brand-new object every call**. React compares snapshots with `Object.is`; a fresh object always reads as "changed," so it re-rendered on every commit → forever. The Context view is the only surface that mounts this hook, so only it crashed.

## Fix

Cache the parsed visibility map and return the **same reference** until the underlying localStorage string actually changes (a write here, or a cross-tab storage event). Stable ref → `Object.is` true → no phantom re-render. Loop broken.

## Note on validation

`tsc`, `eslint`, and `next build` **all passed with the bug present** in #53 — a render loop only manifests at runtime, not at build time. So this fix is verified by the `Object.is` snapshot semantics (and reproducing/opening the view), not by a green build. All three still pass.
