## Description

Two things from your feedback: a build (priority pill on cards) and a cleanup (the confusing Urgency sort).

## 1. Priority pill on every Next-Actions card

The matrix-cell **pill** (🔥 Critical, 🚨 Urgent, 📈 High-Leverage, …) now shows on **every card in the list and board views**, among the other pills — previously it appeared only on the dedicated Priority view. So you can read a task's priority at a glance wherever you are.

The delegate/schedule/eliminate **nudge** badge stays **alongside** it — they're different signals: the pill is *what the task is* (its priority level), the nudge is *what to do about it*. On the Priority view (already grouped by level) the pill is icon-only and the nudge is hidden, to avoid repetition.

## 2. Dropped the Urgency sort

**Your question was the right one.** Here's the distinction:

- **Priority** = the matrix cell, computed from *important × urgent × leveraged*. The holistic "how much does this matter" rank.
- **Urgent** = a single derived boolean: overdue or due within 48h. It's just *one input* to priority, derived from the due date.
- **Due date sort** = orders by the raw deadline.

So **"Urgency" as a sort was redundant**: it only bucketed tasks urgent(0)/not(1), which "Due date" already does with finer resolution (soonest first), and which "Priority" already folds in. It added nothing but confusion. Removed it from the sort dropdown — **Priority** and **Due date** remain. (Urgency still exists as a *concept* — it drives the priority matrix and the ⏰ signal — just not as its own sort.)
