## Description

Two follow-ups that make the WhatsApp vertical searchable *and* actually connectable.

## Features

- **Semantic search (W10)** — `/whatsapp/search?hybrid=true` finds chats by meaning, and since the embedded text is the message body **+ voice-note transcript**, a spoken *"kal AWB bhej dunga"* is findable. Recall stays **lexical** (every keyword hit returned); semantics only re-rank (`0.5·ts_rank + 0.5·cosine`). **Reuses the proven email/mem0 embedder** (`litellm.aembedding` → gateway `/v1/embeddings`) — no new infra. Migration `111_whatsapp_embeddings.sql` mirrors the email vertical's migration 73 (pgvector `vector(1536)`, ivfflat cosine). OFF by default (`whatsapp_semantic_search_enabled`); the W9 sweep backfills embeddings; the companion agent's search benefits automatically.
- **Connect-a-number wizard (W11)** — makes the app usable. The connect flow was a *disabled* "Embedded Signup" button; this replaces it with a guided, **verifiable** wizard at `/whatsapp/connect`: prerequisites (with links to the exact Meta pages) → webhook config (copy buttons) → credentials + a **"Test connection"** that calls Meta's Graph API for real (new provider `get_phone_number_profile()`), so **Connect is gated on a successful test** and a broken token is never saved → done. Backed by `POST /whatsapp/accounts/verify` (never writes; surfaces Meta's own error) and `GET /whatsapp/connection/info`.

## Going live (env vars)

The wizard/webhook need three env vars on the deploy: `WHATSAPP_APP_SECRET` (webhook HMAC verification), `WHATSAPP_VERIFY_TOKEN` (or use the wizard's per-account token), and `WHATSAPP_PUBLIC_URL` (so the wizard shows the real Callback URL).
