## Description

The **Delegate?** priority badge was reading `item.assignee?.name` and rendering "Delegate to {name}?". But the delegate nudge only fires on tasks that are **yours** (NEXT + isMine), so the assignee is *you* — it literally said "Delegate to Vijay?" (delegate the task to yourself).

Fix: drop the name; the badge now just reads **"Delegate?"**.

Suggesting an actual delegate from the org/HR structure (matching the task to a teammate by role) is a tracked follow-up — the data (`import_hr_people`, `people` store, `clarify.ts` `suggestedAssignee`) already exists to build it later.

One-line UI fix; tsc + eslint clean.
