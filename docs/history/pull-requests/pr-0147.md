## Description

## What

The **final Phase 2 item**. Two halves:

### Backend — the projection
`_digest_categories` / `_digest_top_senders` no longer run their own SQL — they
**compose** `analytics._categories` and `analytics._noisy_senders` under the
digest's own scope (this account, **inbox-only, self-excluded** — the digest email
itself never inflates the next digest) and window. The analytics helpers were
already scope/window-parameterized, so **analytics.py is untouched** — zero risk to
the Analytics screen's numbers. The configured-category filter became a post-filter
on the composed rows (same canonicaliser).

**Two deliberate semantic upgrades** (the point of 2.7 — "digest stops re-deriving
*wrongly* what analytics already computes correctly"):
- the category breakdown now **matches the Analytics chart** (was the
  `email_senders` rollup, which disagreed — message categories + per-thread status
  fallback is the audited-correct computation);
- "Top senders" → **"Noisy senders you never answer"** (raw volume on a founder's
  mailbox just lists colleagues; the never-answered ranking is the one Analytics
  already replaced it with).

### Frontend — the dialog merge
ONE self-contained `DigestSettingsDialog` (categories + schedule + send-to-email;
fetches settings + rule names itself; `onSaved` syncs the embedding screen)
replaces the **two drifted copies** — DigestView's schedule-only dialog and
AI-Settings' full one. Both deleted, plus SettingsTab's now-dead `ruleNames` state.
