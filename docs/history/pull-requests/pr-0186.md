## Description

## What

A 🔔 **Nudge** action on each "Waiting on them" dashboard row opens the thread with an AI-drafted follow-up ready to review — so chasing a stalled thread is one click. Drafts only; confirm-before-send is untouched, nothing is sent.

## How

Reuses the draft-from-dashboard machinery — a new `"nudge"` viewer command that opens the composer and auto-runs the AI draft. Two differences from `reply-ai`:

- **Reply-all, not reply.** On an awaiting thread the last message is usually *ours* (we replied, we're waiting), so a plain reply would address us and filter out to nothing. Reply-all keeps the original recipients — the people we're waiting on.
- **Seeds a follow-up instruction** ("write a brief, friendly follow-up… gently nudge for a reply") via a ref the draft consumes once, so a manual AI draft still uses the user's own typed instruction.

Frontend-only. `tsc --noEmit` clean.

## Try it

Dashboard → "Waiting on them" → hover a row → 🔔 → the thread opens with a follow-up composing.
