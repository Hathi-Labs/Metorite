## Summary
- Evaluated two externally-shared Claude Skills (`ui-styling`, `ui-ux-pro-max`) for content worth porting into `agent-app-builder/instructions.md`. `ui-styling` (shadcn/Radix/Tailwind) doesn't fit T2's fixed esbuild pipeline. `ui-ux-pro-max`'s checklist surfaced a real gap: built apps' injected control CSS (`SandboxedHtml`) sized buttons/inputs at a 36px minimum tap height, undershooting both the Apple HIG/Material 44px standard and CommandCenter's own mobile nav bar, which already uses 44px — bumped to match, and `instructions.md` now states the number explicitly.
- Fixed the shared `AgentChat` model picker (`/api/models/all`, used everywhere including the App Workshop builder chat): speech-to-text models (Deepgram, AssemblyAI, Whisper) enabled via Settings → Models for the Note Taker's STT tier were leaking into the chat/Custom-App model picker with no capability filtering, even though they only transcribe audio and can't drive a chat completion. Added `isVoiceOnlyModel()`, mirroring the gateway's existing `_is_transcription_model` heuristic, to exclude them.
