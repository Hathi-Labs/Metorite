## Description

## Why

The Clarify dialog showed the same decision **twice**: the "Assistant recommends" block, and directly beneath it the full Sort→Shape form pre-seeded with the identical values — ~10 always-expanded subfields (Size, Outcome, Next action, Steps, Owner, When, Energy, Context, Priority, Where). While the user agrees with the proposal, the form is pure duplication — that's the clutter.

## Clarify — progressive disclosure

- The manual Sort→Shape form is now **collapsed behind an "Adjust" button**. The dialog reads as one calm card: title → recommendation → **Accept / Adjust / Trash**. One decision at a time.
- **Re-clarify opens expanded** (the user came specifically to edit), and the form **force-opens whenever the proposal can't apply as-is**, so the missing piece (an assignee, a destination list) is visible instead of a dead button.
- **Bug fix:** "Accept & next" used to silently no-op when the decision couldn't build (e.g. a delegate proposal with no assignee picked). It now disables, and the form opens to show what's missing.
- **Bug fix:** the "Organize it" button lived inside the actionable-only block — picking Reference/Someday/Trash in the form had *no visible apply button* (Enter-only). It's now outside, always present when the form is open.
- Removed the redundant header tagline. A "break into steps" proposal still shows its editable numbered step list inside the recommendation block before accepting.

## Mobile

- **Clarify sheet**: stable near-full-height sheet on mobile (was a content-sized half-sheet that jumped around as the AI proposal arrived).
- **Clarify title**: an auto-growing textarea so a long capture **wraps and stays fully readable** — you can't clarify what you can't read (it truncated at ~30 chars on a 390px screen).
- **Next Actions header**: wraps gracefully (controls drop to their own row) instead of crushing "My Next Actions" into a broken two-line title.
