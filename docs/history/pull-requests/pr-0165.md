## Description

## Board card corners

On the Next Actions board, each card now shows the **priority pill in the top-left corner, above the task name** (it's the ranking signal, so it reads first) and the **action nudge (Delegate? / Schedule? / Eliminate?) in the top-right corner**. The list row keeps both in its wrapping meta as before.

## Every suggestion acts in place

The nudges now do their thing directly, on every surface — including the list's Suggestion column pill, which was display-only:

- **"Do It" / "Schedule?"** → opens the add-to-calendar popup (next free slot / tomorrow / exact time).
- **"Delegate?"** → a new **DelegatePopup** scoped to that one task:
  - lists **only eligible delegates** — a synced task's workspace members; the org roster for a local task;
  - **synced task**: multi-select the owner set, one Apply patches `assignees` (back-syncs the add/remove delta to ClickUp);
  - **local task**: shows "this task is private to you — picking someone promotes it to ClickUp", and the picked person routes into the existing promote-to-ClickUp destination dialog — the same flow as the detail card's assignee, without opening the whole task.
- **"Eliminate?"** → the existing popup offering **Move to Someday / Maybe** or **Delete** (with confirmation) — already matched the ask, unchanged.

## Mock data

Five demo tasks now carry realistic `important`/`leveraged`/due flags so the priority matrix actually shows in demo mode — previously every card was "Low Priority", hiding the corners, the nudges, and the ranking.
