## Description

## What & why

Reply Zero's **History** is a *global* feed of what the rules engine did across the mailbox. This adds its **per-message inverse**: open one email → **More ▸ View activity** → read its whole story, oldest-first.

Closes the last inbox-zero History parity gap (master plan **3.9**).

## Changes

- **Backend** — `GET /email/messages/{id}/timeline` assembles the *received* anchor + one event per `email_executed_rules` row for that message, chronological, scoped to the caller's own accounts (unowned/unknown → 404). **Reuses the existing audit rows — no new table, no migration.**
- **Frontend** — `MessageTimelineModal` renders the events as a vertical timeline: received / rule-applied / no-match / failed, each with action chips and action-error surfacing. Wired into the `EmailDetail` "More" menu.
- **Test** — `tests/unit/test_email_message_timeline.py`: assembly order, ownership 404, failed-run error passthrough.
