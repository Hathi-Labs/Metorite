## Summary

The control plane landing page previously showed a single hardcoded Chat card. It now renders every app from `NAV_SECTIONS` in `src/lib/nav.ts` — the same source of truth used by the desktop sidebar and mobile menu drawer — so the landing page stays in sync automatically when apps are added.

- **Apps** render as an icon card grid (2 columns on mobile, up to 4 on desktop): Chat, Email, WhatsApp, Memories, Tasks, Notes, Dashboard, Live Activity, Artifacts
- **Configure** and **Build** panes follow as compact rows
- Styling follows `DESIGN_SYSTEM.md` conventions (semantic color tokens, `tech-transition`, `rounded-xl` cards, `gap-3` grids), working in both dark and light themes
