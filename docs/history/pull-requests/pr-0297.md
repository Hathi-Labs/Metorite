## Why

Three mobile chat UI fixes (from screenshots), all touch-affordance / layout issues.

### 1. Conversation delete button unreachable on touch
The per-conversation Trash button was `opacity-0 group-hover:opacity-100` — a pure hover-reveal, so on a touch device (no hover event) it never appeared. That's why the trash icon was nowhere to be found in the conversations drawer. Added `[@media(hover:none)]:opacity-100` so it's **always visible on touch** while staying hover-revealed on pointer devices. Since the control is now one tap away and deletion is irreversible (it wipes the thread's history), guarded `handleDeleteSession` with a confirm.

### 2. Composer grows tall and stays tall
The chat textarea auto-grows by setting `height` **imperatively** in `onInput`. Sending clears the text via React state (`setInput("")`), which doesn't fire `onInput`, so the inline height from the just-sent multi-line message is never reset — leaving a giant blank box while the agent processes. Added an effect that resets height to `"auto"` whenever `input === ""`.

### 3. Bottom nav taller than needed
The shared `MobileBottomNav` had doubled vertical padding (`<nav>` `py-1.5` + each tab `py-1.5`) and 21–22px icons. Trimmed to `py-1` and a uniform 20px icon (accent tabs keep emphasis via color + stroke weight). Reclaims ~10px app-wide.
