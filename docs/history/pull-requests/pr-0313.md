## Summary

Two reports from the Email Cleaner.

### 1. Expanding a sender froze the page
The drill-down fetched **25 messages *and their full bodies*** — `/email/search` returns `body_text` + `body_html` — so opening a marketing sender pulled megabytes of HTML across the wire and parsed it on the main thread, in order to render subject + snippet and throw the rest away.

- **`/email/search` gains `light=true`**: keeps the SELECT's *shape* (every consumer, `_row_to_message` included, reads both body columns) but returns them empty. Orders of magnitude off the payload for any caller that only renders list rows.
- The drill-down now loads **4 at a time** behind a `Show N more (x of y)` button, in light mode.
- It also remounts per `(sender, category)` so a scope change starts clean rather than flashing the previous scope's page.

### 2. The "Conversation" chip named a category that doesn't exist in AI settings
It is a **sender-level inference** — several of that sender's messages carry Reply Zero conversation labels and *none* carries a cleanup label — not anything a rule writes onto a message. As a chip it was untraceable to any rule, matched no filter tab, couldn't be corrected, and it **masked the labels the user's rules had genuinely applied**: the chip list only ranked cleanup categories, then fell back to the sender-level value when there were none.

- Chips are now exactly the labels a rule wrote onto that sender's mail: cleanup categories first (they drive the filter tabs), then Reply Zero's conversation state — **Needs Reply, Awaiting Reply, FYI, Done, Follow-up** — each most-used first. Legacy spellings (`reply` / `to reply` / `actioned`) collapse onto their modern display name rather than duplicating it.
- The sender-level category is no longer read for display but is **untouched as a classification**: "Conversation" is still what ranks a human correspondent above bulk mail in "important emails".
