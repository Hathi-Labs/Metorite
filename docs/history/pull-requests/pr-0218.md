## Description

A focused pass on how the calendar leverages AI to plan the day — the "Plan my day doesn't take my prompt", the time-setting UX, and mobile.

## Why "Plan my day" seemed to ignore the prompt
The standing prompt **and** the per-run note are correctly wired to the LLM. But when the model call fails, the planner silently fell back to deterministic priority ranking — which ignores both — with no signal, so it read as "my prompt does nothing." Fixed by making the fallback visible:
- the planner now returns `ranked_by` (`ai` | `priority`);
- the panel shows an **"AI-ranked for your prompt"** badge on success, or a clear amber note when it fell back ("AI ranking was unavailable, so this used priority order — your note and standing prompt weren't applied. Try Re-plan.").

## Where the default prompt is / how to override it
- Settings now **shows the built-in default** via a "See the default the AI is using" toggle (mirrors the gateway's `DEFAULT_PLANNING_PROMPT`), and explains the textarea **overrides** it while the Plan-my-day note is a one-off on top.
- The Plan panel labels the note field ("Anything special about today?"), says it's applied on top of the standing plan, and links straight to the standing prompt in Settings.

## Setting times
- Replaced the raw `0–23` hour number boxes with **clock dropdowns** (`7 AM`, `12 PM`, `10 PM`) across working hours, lunch, energy windows, and recurring windows.

## Mobile
- **Calendar settings** was an absolutely-positioned popover at `z-30` — *below* the `z-50` bottom nav — so its lower controls were hidden and unreachable on a phone. It's now a **full-height bottom sheet** above the nav: tap-to-close backdrop, sticky header, scrollable body, safe-area bottom padding. Still an anchored popover on desktop.
- The **Plan-my-day panel** is now a bottom sheet on phones (anchored bottom, scrollable body, footer padded past the home indicator), so the note field and Apply/Cancel are never cut off by the menu bar.
