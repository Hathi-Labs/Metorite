## Summary

Duplicate any app you can *view* (not just edit) as your own new editable draft — the next item off the gap-analysis list. Chosen because it also makes the still-open "templates gallery" item nearly free afterward (a template is just a fork source flagged as curated).

- **New `POST /{slug}/fork`** (`lifecycle.py`, mirrors `create_app` closely): copies the source app's source files only, via `durability._read_workspace_files` (reused, not re-walked — same skip-dotfiles/VCS/build-dirs rules the existing `app_files` mirror already uses). Deliberately **not** copied: `app_data` (runtime storage — starts empty), `app_grants` (sharing resets, forker is sole owner), `app_audit` (usage history stays with the original), `app_versions` (fork is an unpublished, private draft). `app.json` gets the corrected slug/name; the new workspace gets a fresh `git init`, not the source's history.
- View access is enough to fork (no edit grant required) — "make my own copy of a shared team app" is exactly the point, most useful for non-editors.
- **Frontend**: a Fork button on the published-app run page topbar (where a non-owner viewer actually lands), next to "Open in Workshop"/Info. Navigates straight into the new fork's Workshop on success.
