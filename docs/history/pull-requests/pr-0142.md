## Description

## What & why

Reworks the Next-Actions UI (cards, list, board, filter) so status, priority, and context all read with one consistent visual language.

### Status control (no more Done button)
- The card's status control is now a single **status indicator** — the "Done button" look is gone. The last stage is just Done like any other stage, coloured by the same `stageAccent` the board columns and list headers use, so status reads the same everywhere. Clicking it is the only way to change status.
- Placement follows the surface, removing redundancy:
  - **Kanban board** — the column *is* the stage, so the per-card pill is off.
  - **Status-grouped list** — the section header *is* the stage, so the pill is off.
  - **Everywhere the stage isn't shown structurally** (Engage, Priority, a lens-grouped list, the flat Waiting/Someday/Done lists) — the pill stays on the card so status lives on the card itself.
- On the desktop columnar list, grouping by a **lens** (Priority/Energy/Context/Suggestion) hid status (the header carries the lens, not the stage). The status pill now rides as a **leading chip on the Name cell** there — next to the title, no fixed column to crush the name. Extracted into a shared `StatusPill` component (card + row share it). The Name grid track also gets a 140px floor so titles never collapse to nothing when every column is shown on a narrow window.

### Per-context colours
- Each `@context` gets its own stable colour (`contextColors.ts`) on the card chip, the list Context column, and the filter — instead of every context sharing the one primary tint.

### Lucide icons for priority & suggestions
- Priority levels and action-mode suggestions use lucide icons (`priorityIcons.ts`) on the card badges, the list Priority/Suggestion columns, the grouped section headers, and the Filter popover + active chips — replacing the emoji. Suggestion icons are unified with the mode column (delegate → UserPlus, schedule → CalendarClock, drop → Ban).
