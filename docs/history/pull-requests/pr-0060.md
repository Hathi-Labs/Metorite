## Description

## Agent workbench: persistence, memory scopes, side-panel editor + report kit

Makes MAF agents durable and gives the chat app a document surface.

### Files & memory persistence
- Postgres blob store backing the three agent folders (`agent-data/`, `inputs/`, `outputs/`); the store is authoritative and the on-disk workspace is a rehydratable cache (write-through, fault-in on read-miss, rehydrate on load). Keyed on agent name.
- Durability test covering put → rehydrate round-trip, version dedup, delete-keeps-history, and idempotent rehydrate. Live DB tests skip automatically when no DB is present (CI-safe).

### Memory scopes
- Three memory scopes — user, agent (shared across users of the same agent), and org-wide — with recall/save tools for each.

### Self-mutation
- Approving a native-MAF agent's self-mutation opens a review PR editing the agent in place. Inert unless explicitly configured. See `docs/DESIGN_LIMITATION_native_maf_mutation.md` for scope and constraints.

### Chat
- VS Code-style collapsible document side panel: tabbed live Markdown/HTML preview + edit, auto-opens on agent write, feeds open files into agent context.
- On-brand HTML report kit (pure CSS / inline SVG blocks: stats, charts, decision boxes, diagrams, tables, timelines) so agents compose reports without hand-rolling markup. Same blocks render inline in chat or as a saved full-page report.
- `design.md` design system injected into every agent.

### Validation
- Backend: unit tests pass; migrations are idempotent.
- Frontend: `tsc`, `eslint`, and `next build` all clean locally.
