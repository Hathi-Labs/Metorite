## Description

Adds one entry to the `impeccable` skill's layout anti-pattern checklist, capturing a lesson learned from the mobile-nav work.

**The anti-pattern:** a row of equal siblings that must *all* stay visible (bottom-nav tabs, a segmented toolbar) built with a hard `min-w-[Npx]` per item plus padding inside `justify-around`. It overflows the moment the summed minimum exceeds the smallest target viewport (320px).

What makes it worth writing down is that it's a **latent** regression — correct at 3 items, clipped when someone later adds a 4th or 5th. The fix is `flex-1 min-w-0` so siblings distribute the row and can never overflow; fixed min-widths + horizontal scroll are reserved for lists whose item count is genuinely unbounded.
