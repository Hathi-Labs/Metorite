## Description

Builds the "companion + intelligence + management" layer on top of the existing WhatsApp triage/automation core. Six self-contained features, each independently tested. **Zero Zoho/Odoo dependency**, official WhatsApp Cloud API only, carrying the vertical's doctrines throughout (deterministic-first, sentinel-on-failure so the LLM never fabricates, watermarked idempotency, human-in-the-loop for anything outbound).

## Features

- **Group intelligence** — one cached AI summary per group chat (what was discussed, sentiment, whether the founder was addressed, ≤5 points worth their eye). The model's `mentions_you` is OR'd with a deterministic @mention check so a direct address is never missed. Bounded, watermarked schedule/digest trigger — never the hot webhook path.
- **Waiting-on nudges** — the promises others owe the founder become one-tap AI chases. Gentle draft in the thread's language, reviewed and sent through the existing composer (the nudge seam never sends). Surfaced in the digest and the per-chat drawer.
- **Voice-note transcription** — voice notes stop being invisible `[voice]` blobs: transcribed via the platform STT tier, folded into `transcript_text`, and re-run through the *same* deterministic classifiers so a spoken "kal AWB bhej dunga" becomes a real waiting-on commitment. Searchable (FTS already covers transcripts), with a one-tap Transcribe chip.
- **Companion agent** (`apps/agents/agent-whatsapp-assistant`) — a MAF agent giving conversational command of the vertical: brief, triage, search, waiting-on, group summaries, transcription, and reply/nudge drafts. **Drafts only — there is deliberately no send tool**, so a free-form reply stays the founder's own tap and one-to-many goes through the Action Broker. Runs on the BYOK LiteLLM tier.
- **Chat snooze / remind-me** — defer a chat out of the queue until a chosen time; it auto-expires (a pure queue filter, no batch), and a new inbound message wakes it while an outbound reply never does. New "Snoozed" nav stream + a Snooze menu in the composer header.
- **Pulse (analytics)** — the founder-CEO's "am I keeping up?" view: typical reply time (median + p90), who has waited longest, inbound load by intent, busiest chats. Read-only projection at `/whatsapp/insights`.
