## Description

> We don't need the "My Next Action is to…" dropdown anymore — it's all in one view. My Next Actions should just be an unclickable section, under which we have Context, Priority, and Engage Now — the slices we cut our next actions by.

## Change

**"My Next Actions"** is now an **unclickable section header** (like "Higher altitude" / "Workspaces"). Beneath it sit the three slices of my next actions:

- **Context** → the default list/board, sliced by the in-view @context pills
- **Priority** → the matrix lens
- **Engage · Now** → do-able-now

Priority and Engage moved out of their old standalone nav positions into this section. The old expandable **@context drill-down** (chevron + one row per @computer/@calls/…) is **removed entirely** — context selection lives in the in-view pills now. The `NextActionsRow` component is gone (net −108 lines).

The Context slice stays highlighted even when an @context pill is active (it's still the Context view).

Frontend-only, no backend touched. `tsc --noEmit` + eslint clean.
