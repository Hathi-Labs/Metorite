## Description

Two recording-quality improvements to the AI Note Taker.

## 1. Microphone picker + live level check ("green room")
Fixes the Windows case where recording silently fails because the browser's default mic is the wrong or muted device.

- **Choose your mic** on the ready screen (Google-Meet style device dropdown), with the choice **remembered across sessions** (localStorage).
- A **live input-level meter** confirms the mic is picking up sound *before* you record — a flat bar tells you to switch devices instead of discovering an empty transcript afterward.
- The chosen `deviceId` is threaded through the recorder; if that device is gone at record time (unplugged headset), it **falls back to the system default** rather than failing to start (`OverconstrainedError`/`NotFoundError`).

## 2. Smart speaker naming — auto-detect self-introductions
- New `speaker_id` module runs an LLM pass over the **diarized** transcript and maps each anonymous label (`S1`/`S2`) to the name that speaker states about **themselves** ("Hi, I'm Priya", "Alex here").
- **Precision over recall:** being addressed/mentioned by another speaker never names anyone; unsure → stays anonymous.
- **Non-destructive** merge (never overwrites a name the user set) and **fail-safe** (any error leaves the transcript unchanged, never raises).
- Runs **automatically** after diarization so notes/action owners/follow-up email use real people. Also exposed as an **"Auto-detect names"** button on the meeting detail and a `POST /meetings/{id}/identify-speakers` endpoint for already-transcribed meetings.
- Only engages when the transcript is diarized with ≥2 speakers (a solo recording is correctly skipped).
