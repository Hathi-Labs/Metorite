## What you asked for

> A checkbox to select one or multiple tasks, then Archive or Delete — with an "Are you sure?" popup for multiple — back-propagating into ClickUp. ClickUp can't delete via API, so delete = archive upstream.

## What shipped

**Checkbox multi-select on every Next-Actions surface.** Previously select mode only worked on the flat lists (Done/Waiting/…). Now the **status-grouped list and the Kanban board** support it too:
- Select state lives in the store, so it survives the list ⇄ board toggle and clears when you change views.
- On the board, entering select mode drops you into the grouped list with checkboxes (checkboxes + drag on the same card fight each other). Drag-reorder is disabled while selecting.
- The existing bulk action bar (**Archive** · **Delete**) and the **"Are you sure?"** confirm modal already handled single *and* multiple ("Delete 3 tasks?", Enter/Escape) — now wired across all surfaces.

**ClickUp back-propagation:**
- New `provider.archive_task` → ClickUp `PUT {archived}`, broker-gated, 404-safe.
- **Delete** removes the task locally and **archives (not hard-deletes) the ClickUp task** — recoverable upstream, per your requirement.
- **Archive / Restore** (single + bulk) now mirror the `archived` flag upstream for SYNCED tasks — best-effort, after the local commit, one provider reused per account.
- Confirm-modal copy updated: "archived in ClickUp (recoverable there), not permanently deleted."

## Semantics note

Since both Delete and Archive now archive the ClickUp task, they're identical *upstream*. They differ *locally*: **Delete** is destructive (soft-delete → purge; gone from your app), **Archive** is a reversible hide (stays in your Archive view, Restore brings it back).
