## Description

Answers: *"let me block out recurring habits like lunch/rest, and reserve days/hours for specific kinds of work like calls, meetings, or deep work — flexibly, easy to change."*

A single flexible list of **recurring windows** the AI planner reasons over, editable freely in Calendar Settings.

## Two kinds of window
- **Block** = protected time — the planner treats it as busy so **no tasks land there** (lunch, rest, gym, family, workout). Honored by Plan, Rollover, Replan, and the nightly job.
- **Focus** = reserve time for a **kind of work** (deep work, calls, meetings, admin, R&D). These become themed energy-preference windows (deep→high, calls/admin→low, meetings→medium) so matching tasks are drawn in *geometrically*, **and** their labels are handed to the LLM so it batches the right work there.

Both surface in the plan notes ("Protected: Lunch, Gym"; themed windows fed to the ranker). The chat planner benefits automatically (persona updated).

## Flexible by design
Each window has: **days** (a compact S-M-T-W-T-F-S picker; none selected = every day), **hours**, **kind**, **label**, and **theme** (focus only). Add / edit / remove freely — it's one JSONB list (`gtd_settings.day_templates`, migration 94), no schema churn per change.
