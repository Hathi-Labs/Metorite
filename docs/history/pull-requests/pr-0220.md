## Summary

Follow-ups to #206, from mobile testing of the reply composer:

### 1. The AI draft bar's instruction was silently dropped (functional bug)
Typing a prompt into the "Draft with AI" box and hitting **Draft** on an empty reply changed nothing: `compose_assist` routed an empty-body reply through `_agent_draft_reply` **without passing `req.instruction`**, so the user's steer never reached the model (the dashboard "nudge" preset rode the same path and was equally ignored). The instruction only worked in improve-in-place mode.

- `_agent_draft_reply` now takes `extra_instructions` and weaves it into the drafter's instructions alongside the follow-up/confidence notes.
- `compose_assist` passes the user's AI-bar instruction through on the draft-from-scratch reply path.

### 2. Inline reply footer overflowed the card horizontally on phones
The action group (AI ✨ / attach / AI files / Pop out / Discard / Send) is `flex-shrink-0` and wider than a mobile viewport, and the composer card is `overflow-hidden` — so the Send button got clipped at the right edge.

- Below the `sm` breakpoint the labels compress to icons (Pop out → external-link, Discard → trash, AI files → sparkles) with tighter gaps, so the whole row including Send always fits; text labels return at `sm+`. Icon buttons keep tooltips and gain `aria-label`s.
