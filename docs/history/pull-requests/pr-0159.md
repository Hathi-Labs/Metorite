## Description

The rail's **Timebox** button only dropped a task into the day's first free slot — you still had to drag the resulting block to the time you actually wanted, so the button was two steps where a drag is one, and it consumed a row on every card.

## Changes
- Rail cards now share the calendar block's interaction grammar: **click** opens the task card, **click-and-hold** drags onto the grid at the exact slot you want. A completed drag never emits the click; the ★ One-Thing star stops propagation.
- Timebox button removed; cards are one line shorter and the rail shows more tasks per screen.
- Honest undo labels: dropping an unscheduled card reads **"Scheduled"** in the undo toast; moving an existing block reads **"Moved block"**.
- Rail header hint updated ("Drag a card onto the grid to timebox it · click to open"). Touch scheduling keeps its own path (FAB → sheet → tap a slot / Plan my day) since the rail is desktop-only.

## Verification
`tsc` / ESLint / `next build` clean. Playwright: rail card click opens the task card; mouse-drag from rail to the 4 pm slot lands the block there with the "Scheduled"-family undo toast.
