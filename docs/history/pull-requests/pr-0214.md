## Description

Follow-up to #213. The sherpa-onnx trial deployed and enabled cleanly (models downloaded, flag on), but the deploy log revealed the box has **no `ffmpeg`** — which `local_diarization.py` needs to decode meeting audio → 16 kHz PCM:

```
==> [trial] Local diarization (sherpa-onnx), LOCAL_DIAR=1
    ! ffmpeg missing — decode will no-op
    + segmentation model (int8, ~6MB)
    + speaker-embedding model (CAM++, ~27MB)
    local diarization ENABLED
```

The VPS never needed ffmpeg before (cloud STT decodes server-side), so the pass was silently no-opping to a speaker-less transcript (fail-safe working as designed — nothing broke, but no speakers either).

**Fix:** install ffmpeg on demand in the `[trial]` block (apt, guarded on `command -v`, idempotent). After this deploys, an enabled Whisper transcription actually produces speakers.

`deploy.yml` validated as YAML. No app-code change.
