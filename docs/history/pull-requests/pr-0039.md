## Description

Two independent changes, one per commit.

## 1. `refactor(apps)` — group `apps/` into `services/`, `agents/`, `skills/`
The flat `apps/` folder mixed three kinds of unit distinguished only by name prefix. Now grouped by lifecycle so the separation of concerns is structural:

- **`services/`** — deployed FastAPI processes (`gateway`, `orchestrator`, `ingestion`, `email_ingestion`, `reconciler`, `action_broker`)
- **`agents/`** — runtime-loaded agent definitions (`agent-*`), loaded via `build_agents()` + `local_path`; never deployed on their own
- **`skills/`** — importable tool packages (`skill-*`) an agent picks up

All 12 dirs moved via `git mv` (history preserved). Every path reference updated: uv workspace globs, `agent_registry.json` + gateway `_AGENT_REGISTRY` local_paths, docker-compose context, deploy/dev scripts, control-plane runtime path, `.vscode` paths, CI filters, path-based tests/evals, and `uv.lock` editable paths (dependency versions unchanged). Python imports are by package name and unaffected. `apps/AGENTS.md` rewritten to document the three groups.

Also fixes a **pre-existing** bug in `replyzero.quick_action`: its relative path to `agent-email-assistant/agents.py` had too few `..` hops and had been dead since the email routes were split into the `automation/` subpackage. Now resolves correctly.

**Verified:** `uv lock --check` clean, `uv sync` clean, gateway route imports, 32 path-sensitive unit tests pass, zero stale path references remain.

## 2. `fix(control-plane)` — frame the full agent figure in the avatar crop
The pixel-art sprites are 128×128 but the character only occupies the middle band (~25–74% vertically). The default `AgentAvatar` crop (`zoom 265%`, `focusY 10%`) parked the window in the empty headroom above the head, so only a sliver of face showed and the body was cut off.

Reframe defaults to `zoom 170%` / `focusY 50%` so the whole character sits centered in the circle. All call sites use the defaults, so this fixes the card, detail header, and chat lists uniformly. Verified with a real headless-browser render across all in-app sizes (18–96px).
