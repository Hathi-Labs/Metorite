## Description

Follow-up to #274. A bot that joins successfully still produces **no live transcript** — the live console stays empty for the whole call and text only appears once the meeting ends. That failure looks like success right up until the meeting is over, which is the worst shape for it to have.

## Cause

The worker's only ASR path was `LIVE_ASR_URL`, a self-hosted WhisperLive-style socket, and nothing sets it on the VPS. Meanwhile the gateway already knows how to stream — it mints AssemblyAI tokens for the browser recorder from the key in Settings → Models. The worker couldn't reach any of that, running in its own container.

## Approach

The worker asks for credentials rather than holding them:

- **Gateway** — `POST /notes/stt/bot-live-token`, authenticated with the shared bot token rather than a user session, returning the same `LiveToken` the browser gets. Provider choice stays in one place, so a bot and a browser can't end up transcribing through different providers.
- **Worker** — `_resolve_asr()` prefers a self-hosted `LIVE_ASR_URL` when set (it costs nothing per minute), otherwise fetches a token and connects to AssemblyAI streaming v3.
- **Deploy** — wires `NOTES_LIVE_TOKEN_URL` by default. Left opt-in, the silent failure above is what you'd get.

Shipping `ASSEMBLYAI_API_KEY` into the container would have been fewer moving parts, but it duplicates the source of truth and widens the blast radius. A re-fetchable endpoint also matters for a reason a join-time handover can't cover: these tokens live about a minute and meetings run hours, so a worker that loses its socket mid-call needs to be able to ask again.

## Protocol details worth flagging

- **Only completed turns are forwarded.** AssemblyAI streams a growing partial for every turn; the live bus appends rather than replaces, so forwarding partials would stutter the same sentence down the console one word at a time. This matches what the browser recorder already relays.
- **Word timings are milliseconds, the bus works in seconds.** The conversion matters beyond display — those spans drive speaker reconciliation against the voiceprint gallery.
- **Deepgram streaming from the worker isn't wired.** It logs that plainly rather than opening a socket that will never produce a transcript.
