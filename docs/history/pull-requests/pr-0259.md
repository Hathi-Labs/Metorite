## Description

An opt-in agent that listens to a live meeting and surfaces a talking point when a moment warrants it. **Off by default**; turning it off cancels the task, which unsubscribes it from the transcript bus — so spend stops immediately rather than the toggle being a lie.

## The cascade is the point

Running a model on every sentence would be expensive *and* noisy. Each stage is cheaper than the next and filters for it:

| Stage | What | Cost |
|---|---|---|
| **0** Windowing | closes on speaker turn, ~40 words, or ~15 s | free |
| **1** Trigger gate | questions, objections/risk, decisions, numbers + debounce + per-meeting cap | **free — most speech ends here** |
| **2** Decide | `tier-fast`, tiny context, strict JSON, confidence floor | cheap |
| **3** Craft | `tier-balanced`, only for what survives | rare |

Stages 0–1 live in `copilot_policy.py` and are **completely pure** — no LLM, no I/O. "Does this deserve a model?" should be inspectable and unit-tested, not emergent from prompt behaviour.

Two details that matter:
- **The cap and debounce are checked *before* the trigger patterns**, so a lively meeting can't run up cost through pattern matches.
- **A bounded rolling state** means the prompt never grows with meeting length — that's what keeps cost flat on a 3-hour call — plus a token-overlap dedup so the copilot can't re-raise a point it already made (the fastest way to become annoying).

## Auditable, and isolated

Output goes to a **separate event bus** from the transcript, so agent chatter never pollutes the record. Events persist to `copilot_event` (migration 121) with **per-event token cost**, making the budget guardrail inspectable rather than a black box. Budget exhaustion pauses and says so in the console.

Every failure mode — LLM error, bad JSON, slow model, budget exhaustion — degrades to *"no suggestion"*. The copilot consumes the transcript; it is never in the capture path.

## Console

Suggestions render on their own channel, each showing **what triggered it** so a tip is inspectable rather than an oracle. Only subscribed while the copilot is actually on.

## Verification
