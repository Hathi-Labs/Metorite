## Description

Four things from your feedback on My Next Actions.

## 1. Grouped-by-status, stated
The Next Actions header hint now says it: *"Tasks assigned to you, grouped by status and sorted by priority."*

## 2. Default sort = Priority
Default sort changed from Manual → **Priority** (matrix rank, Critical first), applied within each status group. You can still switch to Manual (drag-reorder) or any field from the toolbar. Board cross-stage drag is unaffected (it re-files on drop regardless of the sort).

## 3. Action Mode column
New **Action** column showing what to *do* with each task, on every row:
- 🎯 **Do It** — it's yours
- 🙋 **Delegate?** · 📅 **Schedule?** · 🗑 **Eliminate?** — the nudges

Exactly the four suggestions you listed.

## 4. Unified with the "action mode grouping"
The column and the existing **"Action mode" group-by lens** now read from **one shared source** (`ACTION_MODE_META`), so they use the same labels and can't drift. The old lens wording ("Do — my work", "Consider dropping") is replaced by the new set. Group by Action mode and each section header matches the column exactly.
