## Description

## What

Completes **2.11** (first half was #139). Converts the deferred sites — the `/send`
handler and every background/scheduler job — onto `provider_session`, so the
instantiate → authenticate → persist-rotated-creds dance now exists in exactly one
place across the whole email package.

### New: unscoped mode
`provider_session(db, None, account_id=...)` — `user_email=None` selects an
**unscoped** account loader (`_provider_for_account_any`) for background work that
has no request user (scheduler ticks, webhook tasks, fire-and-forget cleanups).
Message-scoped sessions still require a user (no background path loads by message).

### Converted
| Site | Mode |
|---|---|
| `/send` (full handler) | user-scoped, 401 on auth fail |
| digest scheduled send | unscoped, quiet-skip on auth fail |
| `_cleanup_thread_drafts`, `upsert_draft`, `send_draft_endpoint` | drafting paths |
| `_bulk_reconcile`, `_create_block_filter`, `_remove_block_filter` | senders background tasks |
| cleanup sweep | unscoped **loader** only — keeps its own auth/persist choreography (summary-error verdicts + success-tail persist) |

### Deliberately not converted
`restore_provider_labels` — must report "unsupported" **before** authenticating
(documented ordering) and needs the raw provider name for its error payload. The
session helper authenticates before yielding; forcing it in would change that
contract for zero dedup value.
