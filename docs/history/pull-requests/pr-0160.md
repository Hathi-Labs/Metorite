## Description

Restores the one-click "first free slot" scheduling where it belongs — the context menu — instead of a space-eating per-card button, and gives overdue blocks the same one-gesture fix.

## Changes
- **Rail card right-click menu**: Open task · **Timebox → first free slot** · Make it the One Thing · Schedule… (exact date/time popup) · Delete task…
- **Block context menu gains "Move to next free slot"** (non-done blocks): re-timeboxes a slipped block into today's first opening from *now*, preserving the block's current length (falling back to the estimate), and excluding the block's own old slot from the busy check.
- Both actions land in the undo toast ("Scheduled" / "Moved to next free slot").
