## Summary

Typing an address in any composer now offers autofill from the people the mailbox already knows.

### Backend — `GET /email/contacts/suggest`
- Candidates union'd from three sources, strongest first: addresses the user has **sent** mail to (To+Cc of the Sent folder), the learned `email_contacts` directory (names parsed from signatures), and the `email_senders` rollup (everyone who has mailed the user).
- Matched case-insensitively on address OR display name; prefix hits rank above substring hits, then by occurrence count and recency. Dedup'd by address; the user's own connected addresses are excluded.
- Scoped to the caller's accounts (optionally one). Best-effort: `[]` on any failure (e.g. the contacts migration not applied) — a typeahead must never error the composer.

### Frontend — `RecipientInput`
Drop-in replacement for the plain comma-separated inputs (same `value`/`onChange` contract):
- Suggests for the **token at the caret**, so editing mid-list completes that address only; already-entered addresses are never re-offered.
- Debounced (200ms, min 2 chars), stale responses discarded; dropdown shows name + address; ↑/↓ + Enter/Tab/Esc keyboard support; mousedown selection so blur can't eat the click. Picking inserts the bare address plus a trailing `, ` ready for the next recipient.
- Wired into all eight recipient fields: inline reply To/Cc/Bcc (EmailDetail), Drafts editor To/Cc/Bcc (ConversationView), pop-out composer To/Cc (ComposePanel).
