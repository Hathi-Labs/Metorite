## Description

Hardening found while auditing the full speaking path end to end.

`transport/calls_audio.py` imports `websockets` lazily inside the socket handler. The package was only present **transitively** — via `uvicorn[standard]`, `openai` and `litellm` — and nothing declared it.

That means a transitive-dependency change would break duplex call audio, and it would break it **at the moment someone pressed Talk**: no startup path touches that import, and no other test exercises it, so nothing would catch it first.

Now declared on the gateway, with a test that imports it so the regression fails in CI instead of mid-call.
