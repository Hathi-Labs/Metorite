## Description

Recreated from #47 after its stack base (#46) merged; rebased onto `main` so the diff is only this feature.

## What you asked for

> A checkbox to select one or multiple tasks, then Archive or Delete — with an "Are you sure?" popup for multiple — back-propagating into ClickUp. ClickUp can't delete via API, so delete = archive upstream.

## What shipped

**Checkbox multi-select on every Next-Actions surface** — previously flat lists only; now the status-grouped list and the Kanban board too. Select state lives in the store (survives list⇄board toggle, clears on view change). On the board, entering select mode drops to the grouped list (checkboxes + drag on the same card conflict); drag-reorder is disabled while selecting. The existing bulk bar (**Archive** · **Delete**) and **"Are you sure?"** confirm modal already handled single + multiple.

**ClickUp back-propagation:**
- New `provider.archive_task` → ClickUp `PUT {archived}`, broker-gated, 404-safe.
- **Delete** removes the task locally and **archives (not hard-deletes) the ClickUp task** — recoverable upstream, per your requirement.
- **Archive / Restore** (single + bulk) mirror the `archived` flag upstream for SYNCED tasks — best-effort, after the local commit, one provider per account.
- Confirm-modal copy: "archived in ClickUp (recoverable there), not permanently deleted."

Delete vs Archive are identical *upstream* (both archive); they differ *locally*: Delete is destructive (soft-delete→purge), Archive is a reversible hide.
