## What's now documented

**§12.3 — the four bugs that each cost a production round-trip**, because they're the kind that hide:

1. A WebSocket cannot live on a feature-gated router — the check takes an HTTP `Request` FastAPI never supplies, so it dies at the handshake. Exempting the path doesn't help.
2. Un-normalised phone numbers produce a JID WhatsApp silently never acks.
3. Timeout budgets must shorten at every hop, or the outermost proxy's generic error masks the real one.
4. meowcaller is `zerolog.Nop()` unless you pass `WithLogger` — we were debugging against a log we'd muted ourselves.

**§12.4 — operating it**: the five env vars and the debugging order that actually finds problems (readiness panel → bridge log → captured-seconds).

**§12.5 — what's still open**, transcription first.
