## Description

## What

Chats in the WhatsApp app rendered as colored initials — no profile picture (DP) was ever synced for anyone. This pulls each contact/group's real WhatsApp profile picture across and renders it in the inbox, falling back to the existing colored-initials look wherever there isn't one yet.

## Why

WhatsApp doesn't push profile pictures proactively over the wire, but whatsmeow (the personal-number bridge) can ask for one per chat. Nothing did that yet.

## How

**Bridge (Go)**
- New `avatars.go`: a fixed-size worker pool (3) drains a bounded queue of "check this chat's picture" jobs, so a history-sync backfill (hundreds of chats surfacing at once) doesn't fire hundreds of concurrent WhatsApp API calls.
- A per-(account, chat) **TTL cache** (24h, in the bridge's own sqlite meta store) means a chat is asked about at most once a day, no matter how many messages it sends. The cached hash doubles as whatsmeow's `ExistingID` param, so an unchanged picture costs a cheap "not modified" round-trip instead of a full re-fetch + re-report.
- Wired from `onMessage` (live traffic — every inbound/outbound message) and `onHistorySync` (one check per conversation) — the history-sync path is what backfills every existing chat's avatar right after pairing.
- "No picture" / "hidden from you" answers are cached too, so they aren't hammered on every message either.

**Gateway**
- Migration `128`: `wa_chat_avatars`, keyed by JID (not the `wa_chats` UUID) — same reasoning as `wa_chat_labels`: an avatar can arrive before the chat's first message has synced.
- `POST /whatsapp/bridge/avatars` upserts; `/whatsapp/chats` `LEFT JOIN`s the avatar URL onto each chat row (1:1, unlike labels' many-to-many).
- The stored value is WhatsApp's own CDN URL — the gateway keeps the pointer, not the image bytes, the same "read-only mirror" posture as the labels sync (#243).

**Frontend**
- `ChatAvatar` renders the real photo once synced, falling back to the existing colored-initials look while missing or if the CDN URL 404s (WhatsApp's picture URLs do rotate). Used in the chat list and the conversation header.
