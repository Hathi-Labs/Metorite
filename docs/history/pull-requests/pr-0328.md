## Two defects found and fixed en route

**1. The shipped overdue badge was wrong by 33 days.** `ItemList.tsx` carried `const MOCK_NOW = Date.UTC(2026, 5, 30, …)` and used it for the **real** overdue count behind "N overdue — needs a nudge". Mock-era residue on a live surface, drifting daily. Four copies removed (the audit found three; the implementer found a fourth in `TaskCard.tsx`, the component every flat list row renders).

**2. The in-app Delegate path never wrote `expected_by`.** `DelegateDialog` → `taskStore` → `items.py` passed no due date, so the insert stored NULL and `isWaitingOverdue` always returned false. The exact §12 journey the slice cites — *"delegate a task to a teammate, see it on Waiting For, get an overdue flag"* — produced no flag at all; only provider-sourced rows (ClickUp sync, email capture) worked. Fixed at the backend so the stored record is honest at delegation time rather than papered over at render time in every consumer.
