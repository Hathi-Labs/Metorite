## Summary

Plain Enter in the Agent Chat composer (and the message-edit box) used to fire the prompt, so a mid-thought line break sent half a message.

- **Enter now inserts a newline** (the textarea default) in the shared Agent Chat composer — used by both the chat app and the email app's AI chat.
- The prompt goes out only via the **Send button** — or **Ctrl/Cmd+Enter** as the deliberate keyboard shortcut (can't fire accidentally).
- The message-edit box gets the same behaviour for consistency.
- Hints updated: send-button tooltip now says "— Ctrl+Enter"; edit-box header reads "Ctrl+Enter to send · Esc to cancel · Enter for new line".
