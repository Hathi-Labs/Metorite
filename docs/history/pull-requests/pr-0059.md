## Description

Final generative-UI pass across both runtimes (MAF + GitHub Copilot SDK). `emit_generative_ui` was already injected into every agent; this makes it **eager**, **on-brand**, **genuinely interactive**, stops it **crowding the chat**, and guarantees **full reasoning on reload**.

## What changed

**Eagerness + design guidance** (`write_artifact.py` docstring + both `_tool_injection.py` blurbs)
- A "reach for this eagerly" trigger list: render UI when the answer is data / a metric / status / comparison / checklist / a value to pick or set — with a non-triviality guard (one-liners and long narrative stay as text).
- Tier-3 custom HTML is told to use the real Command Center design tokens (CSS vars) instead of hard-coded colors.

**Sandbox: on-brand + real interactivity** (`SandboxedHtml.tsx`)
- Injects the actual `globals.css` tokens as CSS vars (`--cc-primary/accent/fg/card/border/radius/ease` + state colors); native `button/input/select/textarea/range` are pre-styled on-brand, so generated HTML matches the product by default.
- New `ccSubmit(label, value)` / `data-cc-submit` bridge harvests named form controls and reports user-**set** values (slider/text/select) back on the same validated `postMessage → onAction` path. Tier-3 cards can now **collect input**, not just fire fixed messages. Opaque-origin sandbox + `connect-src 'none'` unchanged.

**No duplicate blue pill** (`GenerativeUIPanel.tsx`)
- `generative_ui` was rendered twice: inline+interactive in MessageBubble **and** as a read-only copy inside the blue "Interactive view … AG-UI" fold. Filtered it out of the panel (`PANEL_HIDDEN_EVENTS`) so it renders once, inline. Panel keeps state snapshots + other custom events.

**Full reasoning on reload** (`stream_relay.py` / `chat_fold.py`)
- Live display never truncated reasoning. The one cap was run-end persistence reading a single Redis `XREAD (count=10_000)`. Added `replay_events(drain=True)` that paginates until the stream is exhausted, so a long run's tail (final answer / late tool events / trailing chain-of-thought) is never dropped on reload. Default `drain=False` preserves every existing caller's single-batch cap.
