## Description

Four cleanups to My Next Actions.

## 1. "Action" → "Suggestion"
The column (and the group-by lens) is renamed **Suggestion** — it's a suggestion of what to do with a task (Do It / Delegate? / Schedule? / Eliminate?), not a status.

## 2. No Assignee filter or column on My Next Actions
Next Actions only ever shows tasks assigned to *me*, so both the Assignee **filter** (toolbar) and the Assignee **column** were meaningless there — removed. The assignee filter is **kept** on the other views (e.g. Waiting For), where tasks are delegated to different people.

## 3. Single "My Next Actions" sidebar entry
Removed the standalone **Priority** and **Engage** sidebar entries. "My Next Actions" is one nav item again — its slices (Priority / Suggestion / Context / Energy grouping, list vs board) are configured **in the view** via the toolbar group-by + column settings, not as separate sidebar destinations. (The views themselves still exist in code; they're just no longer separate nav items.)

## 4. "Default grouping" → "Status"
The group-by dropdown's default option is renamed **Status**, since the default grouping is by status.

Frontend-only. `tsc` + eslint + `next build` clean.
