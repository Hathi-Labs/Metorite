## What this is

Mints **WS-26 — the native CRM that replaces Zoho** — and ships its first slice.

**Research inputs (2026-08-05):** `frappe/crm` (AGPL — data-model concepts only, zero code copied), `trycompai/crm` (MIT — patterns ported, stack does not translate), and a full-tree sweep of our Zoho footprint.
