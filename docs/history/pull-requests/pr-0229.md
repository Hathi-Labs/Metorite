## Description

Reworks planning for the "my day is already half-planned but things changed" case. The two actions now do genuinely different, clearer jobs — and, importantly, **both reshuffle what's already on the calendar and trim the overflow back to your list** (previously Plan treated existing blocks as immovable walls and only stuffed new tasks into the gaps).

## The model

| | Reshuffle existing (not-done) | Trim overflow → back to list | Add new from list |
|---|:--:|:--:|:--:|
| **Fit what's left** (`gtd_replan_day`) | ✓ | ✓ | ✗ |
| **Rebuild my day** (`gtd_plan_day`) | ✓ | ✓ | ✓ |

Both honour 🔒 fixed meetings, done blocks, lunch, recurring windows, energy windows, capacity, and the protected ★ One Thing (never evicted).

## Backend — unified `_replan_core` (replaces `_compute_day_plan`)
- One query for today's scheduled blocks, partitioned into **movable** (flexible + not-done → reshuffled), **obstacles** (fixed meetings + done → avoided), and the **done-minutes** tally.
- Reshuffles movable blocks into the time **actually left** (from now) — including blocks whose time already slipped past **earlier today**, which get swept forward. Movable blocks keep their length (never padded).
- Whatever no longer fits is **evicted**: its schedule is cleared on apply, so it returns to the unscheduled list (`DayPlan.evicted`, distinct from `unplaced`).
- **Trim target = whichever is tighter: time left, or daily capacity minus what's already done today.**
- `include_new=True` (Rebuild) also fills remaining room from unscheduled Next Actions; `include_new=False` (Fit) adds none.
- `_apply_plan_blocks` now clears evicted blocks as well as placing new ones.

## UX
- Buttons renamed to intent — **Rebuild my day** and **Fit what's left** — everywhere (header, rail, startup ritual, schedule sheet, settings copy).
- The proposal panel now **groups** the plan: *Reshuffled · Added from your list · Back to your list (evicted) · Left for another day*, with a one-line headline (`N moved · N added · N back to list · used/capacity`). Apply commits placed + evicted in one undoable op; a Fit that only evicts is still appliable.
- "Fit what's left" shows whenever there's any movable block today (incl. earlier-today overdue).
- Chat tools + persona docstrings + the chat plan renderer updated (shows moved/evicted).
