## Description

Two self-contained follow-ups on the WhatsApp vertical (on top of the W4.1–W7 batch already on `main`).

## Features

- **Saved replies / quick snippets (W8)** — a founder-defined canned-message library (price list, address, GST number, catalogue link) with an optional `/shortcut`. Migration `110_whatsapp_saved_replies.sql` (partial unique index per account so NULL shortcuts coexist but a duplicate is rejected). Account-scoped CRUD at `/whatsapp/saved-replies`; pure `normalize_shortcut`; collisions surface as a 409. **Distinct from templates** — a saved reply is a free-form snippet dropped into the composer *inside* the 24h window, where a template is the Meta-approved message required once it closes. A `/whatsapp/settings/replies` screen manages them; the composer gains a "⚡ Saved" picker.
- **Background enrichment scheduler (W9)** — group summaries and voice transcription were built as bounded, watermarked batch passes but only ran on-demand (WhatsApp is webhook-driven, no background loop). This adds one lightweight loop that periodically sweeps every live account through `summarize_stale_groups` + `transcribe_pending`, wired into the gateway lifespan. **Cost-gated OFF unless `WHATSAPP_ENRICHMENT=1`** (each cycle can call the LLM and STT); interval via `WHATSAPP_ENRICHMENT_INTERVAL_SECS` (default 900s, min 120s). Both passes are per-pass bounded and only touch stale/pending rows, so a caught-up account does no work; a per-account failure is logged, never fatal.
