## Description

## What

Completes **2.1**. The manual-sync route carried a full inline copy of the sync body,
line-for-line duplicating `_sync_account` — the pair had already drifted once
(refresh-token loss + Outlook cursor wipe, review §3.2) and got patched in parallel
instead of collapsed. This deletes the duplicate (**~268 lines**):

- **`trigger_sync`** = ownership check (404) + `_run_manual_sync`, a thin shaper over
  `email_ingestion.scheduler._sync_account` — the **same core** the background
  scheduler and the Graph webhook run. Response shape unchanged
  (`{ok, messages_synced, messages_skipped}`); failures surface as the same 500
  (the core has already stamped `sync_status`/sync-log); new mail still enqueues
  `process_new_mail` after the response; `full=True` forces deep exactly as before.
- **Manual-sync label learning** now flows through the same capture + hook path as the
  scheduler (#141) — one learner, all paths.
- **`resync_account` bug fix**: it called the `trigger_sync` *route* with the wrong
  positional args (`user` landed in the `background` slot; `user` stayed an unresolved
  `Depends`), so every direct resync crashed with a 500 before reaching the provider.
  It now calls the shared helper.

## Tests
- `pytest -k email` → **825 passed**
- Manual-sync parity guards re-pinned on the single core: delegation asserted,
  inline-body markers (`sync_messages`/`upsert_message`/`last_history_id`/
  `authenticate()`/`email_sync_log`) forbidden in `trigger_sync`, resync must use the
  helper; the cred-persist-after-auth and cursor-COALESCE pins now point at
  `_sync_account` where the logic actually lives
- Ingest-path guard updated: `transport/sync.py` is **no longer an ingest path**
  (no `upsert_message`, no `INSERT INTO email_messages`) — pinned

## Risk
Medium-high surface (the manual sync UI path) but the executed code is the
already-live scheduler core — the same code every ~300s tick and webhook has been
running in production. Verify with one manual "Sync" from the UI after deploy.
No migration.
