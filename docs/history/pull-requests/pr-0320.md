## Description

**Merge this first — CI's blocking ruff gate is currently red on `main`, so every open PR fails it for a reason unrelated to its own diff.**

## What broke

`15c8933f` (WS-10 steer) annotates `_route_incoming_turn` and `_apply_turn_decision` with `"TurnDecision"` and imports the type **function-locally** (`agent.py:179`) to avoid an import cycle between the gateway and the orchestrator. With `from __future__ import annotations` in force those annotations are never evaluated, so this is **safe at runtime** — but ruff can't see through it and reports `F821 Undefined name`, which sits in `pr-check.yml:51`'s **blocking** select list.

Found by `ws-verifier` while checking an unrelated docs PR — it ran the real CI command rather than the narrowed one the spec quoted, which is exactly why it was worth running.

## The fix

A `TYPE_CHECKING` import: the linter resolves the name, the cycle never exists at runtime, and the function-local import stays where it is.
