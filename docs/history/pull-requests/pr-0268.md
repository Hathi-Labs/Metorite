## Summary
- Adds a templates gallery to the App Workshop: any editor can flag their own app as a starting point for others via a new `apps.is_template` column.
- The flag is toggled from a small icon on the gallery card (mirrors the existing pin button's optimistic-update pattern), and a new "Templates" filter pill client-side-filters the already-fetched `GET /apps` list — deliberately not a new backend listing endpoint, both to avoid the `/pins`-style route-ordering hazard and because the existing list already applies the correct `can_view` gate (a private app flagged as a template still only shows to people who could already see it).
- "Use" on a template card reuses the already-shipped `POST /{slug}/fork` (fork/remix) rather than a new copy mechanism, landing the caller straight in the new copy's Workshop editor.
- Also fixes a migration-number collision: this branch's `122_app_pins.sql` and the just-merged Live Meeting Copilot PR's `122_meeting_brief.sql` landed on `main` with the same number (a race between two concurrently-developed branches). Renumbered `meeting_brief` to `124` to satisfy `test_migration_prefixes.py`'s uniqueness guard.
