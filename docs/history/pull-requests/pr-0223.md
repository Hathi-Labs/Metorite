## Description

## What this does

Wires the personal-number **whatsmeow bridge** (shipped in #221) into the VPS deploy so it actually **runs** in production — the last step to make QR pairing usable. Until now the gateway + UI knew about the bridge, but nothing started the bridge itself.

## Changes

- **`deploy/hostinger/acb-whatsapp-bridge.service`** — a systemd unit for the bridge. Binds **`127.0.0.1:8790` (localhost only — never exposed through Caddy)**; only the co-located gateway talks to it. Reads the shared `/opt/acb/app/.env`, persists its sqlite session store under a `StateDirectory`.
- **`.github/workflows/deploy.yml`** — before the gateway restart (so the gateway picks up the vars on the same deploy):
  - Ensures `WHATSAPP_BRIDGE_*` in `.env`, generating a strong `WHATSAPP_BRIDGE_SECRET` once (shared by gateway + bridge).
  - When `WHATSAPP_BRIDGE_ENABLED=1`: installs a Go ≥1.24 toolchain on demand, builds the CGO-free binary, installs + enables + restarts the unit.
  - **Fail-safe**: a build/toolchain/start hiccup only skips the bridge — it never aborts the whole deploy. Set `WHATSAPP_BRIDGE_ENABLED=0` to stop + disable it.
- **`.env.example`** — documents the co-located self-host vars.

## Wiring

```
gateway  ──WHATSAPP_BRIDGE_URL=http://localhost:8790──▶  bridge (127.0.0.1:8790)
bridge   ──WHATSAPP_BRIDGE_GATEWAY_URL=http://localhost:8080──▶  gateway
                      both authenticated by the shared WHATSAPP_BRIDGE_SECRET
```

The bridge routes on the gateway authenticate by that shared secret (like the public `/whatsapp/webhook`), so the localhost bridge reaches them without the internal Bearer token.

## Safety / ToS

The service sitting idle is harmless (no paired session = no WhatsApp connection). The unofficial-multi-device ToS/ban risk begins only when a number is actually paired via the app's QR flow. It's localhost-only and one env flag away from off.

## Validation
- `deploy.yml` parses as valid YAML; the added shell is `set -e`-safe (systemd calls made non-fatal; build guarded by `if`).
- The exact VPS build command (`CGO_ENABLED=0 GOFLAGS=-mod=mod go build`) produces a static ELF binary locally.

After this deploys: **Integrations → WhatsApp → Connect → Personal WhatsApp → scan the QR** works end to end on the VPS.
