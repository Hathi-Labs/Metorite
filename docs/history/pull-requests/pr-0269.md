## Description

## What & why

Follow-up to the "Plan through" control (#266): it was **presets only** (Working hours / N more hours). This adds a **"Custom time…"** option that reveals a time picker, so you can plan through an **exact clock time** rather than a fixed step.

- Pick any end time — up to, and past, midnight — so late-night sessions still plan 24/7.
- A time already past today **rolls to the next day** (e.g. picking `1:00` at 11pm plans into the small hours), with a small **"today / tomorrow"** hint showing which day the end lands on.
- Editing the time **re-plans immediately**, same behaviour as the presets.

No backend change needed — the custom time just resolves to the `day_end` the panel already sends; the server-side horizon parsing from the plan note (`"until 2am"`, `"work for 2 more hours"`) still works independently.

## Files
- `calendar/PlanDayPanel.tsx` — `customTime` state + `customEndAt()` (with past-time → next-day wrap), a "Custom time…" `<select>` option, and a conditional `<input type="time">` row.
