## Description

Makes the observability Office view a proper little pixel-art office. **Placeholder art for now** (procedural, generated) with a clean seam to drop in real hand-authored sprites later.

## What's new
- **A pixel-art character at a desk for every agent** (`src/app/observability/pixel.tsx`) — deterministic look per agent (skin / hair / shirt / hair-style from a name hash), three states:
  - **working** — green monitor, gentle typing bob, screen flicker
  - **sleeping at their desk** — dimmed + desaturated, floating `Zzz`, dark monitor
  - **error** — red monitor, shake
- **War-room conference table** — when **≥2 agents are working at once** (multi-agent orchestration), a separate amber card appears with the collaborating agents seated around a conference table (collaboration chatter dots + clickable name chips to open each agent's drawer).

## How the art is done
- **Generated inline SVG pixel sprites** — no external assets (CSP-safe), crisp (`crispEdges` / `image-rendering: pixelated`), theme-agnostic, and `prefers-reduced-motion` aware.
- I rendered the sprites **headless with Playwright/Chromium and eyeballed them** before shipping (desks, sleep state, and the war-room composition) rather than shipping art blind.

## Swapping in real sprites later
`<PixelWorker src={…} />` accepts a real sprite PNG / data-URI per agent+state and keeps the **same animation classes**, so your hand-authored art drops in without touching the page. (Or replace `workerRects()` with your own pixel map — the only contract the page relies on is the `.pw.working` / `.pw.idle` / `.pw.error` state classes.)
