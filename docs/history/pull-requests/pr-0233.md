## Description

The WhatsApp app's section navigation (Inbox / Pulse / Categories / Replies / Rules / Numbers) was a **top bar**, which is inconsistent with the rest of CommandCenter — Email (`AccountSidebar`) and Tasks (`ListsSidebar`) put their in-app nav in a persistent **left column**.

This matches that pattern: `whatsapp/layout.tsx` now renders the nav as a **left sidebar** using the native `bg-sidebar` styling and lucide icons, so the WhatsApp app looks and behaves like the rest of the suite.

- **Responsive**: a compact **icon rail on mobile** (`w-14`, icons only) that expands to a **labeled column on desktop** (`md:w-52`). Connect stays pinned at the bottom.
- The inbox keeps its own triage-stream spine + account switcher unchanged (that's the inbox's content nav; the new column is the app-section nav — same relationship email has between its sidebar and message list).
