## Summary

Three threads of work on the `/observability` office:

**1. Conference breathing animation.** Agents standing around a conference table now play a real Pixel Lab breathing-idle animation (9 frames/direction, south + north) instead of a bare CSS scale. `CrStandee` steps the spritesheet with the same mechanism the seated typing animation uses, falling back to the static standing sprite when frames are absent. Generated for all 9 existing agents.

**2. Reusable character sprite library.** A credit-aware generation campaign produced **8 complete characters** — male + female across executive, engineer, designer, and sales — each with the full animated set the office uses: 8 standing rotations, seated desk sprite, 9-frame typing (posed in front of a monitor), asleep-at-desk sprite, and 9-frame breathing idle (S/N). The campaign generates each character's *entire* set before the next and stops cleanly at ~48 gen/character once the budget can't finish another whole one (no half-built characters). Assign one in **Avatar Studio → "Assign from the character library"**; the office then renders that character's full animated set for the agent via `castFor()`.

**3. Observability tool-calls.** Verified the `kind:"tool"` event path is wired end-to-end (executor `_emit_tool` → `publish_activity` → SSE, forwarded unfiltered → office avatar badge, all keyed on the same `agent` id) and added unit tests locking the round-trip.
