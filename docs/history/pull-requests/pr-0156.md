## Description

On phones the calendar header actions (due-soon pill, replan/plan buttons, settings, view toggle) shared whatever space was left beside the date, which wrapped the "2 due soon" pill onto two lines.

## Changes
- The actions container takes a **full second row** below the title/nav on mobile (`w-full`; `sm:ml-auto sm:w-auto` restores the desktop single-row layout unchanged).
- The Day/Week/Month toggle right-aligns within the mobile row (`ml-auto sm:ml-0`).
- The due-soon pill is `whitespace-nowrap`, so it always renders on one line.
