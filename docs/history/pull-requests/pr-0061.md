## Description

Moves the email search from the sidebar into the **centre of the top bar** and gives it the scope + pill model people expect from Outlook/Gmail.

## What changed
- **Scope dropdown** — search a folder, "All folders", or Starred. Defaults to following the open folder ("Search Inbox"); an explicit pick sticks until the search is cleared.
- **Closable filter pills** — tags, `from:`/`to:`, and unread/read/starred/attachments. Produced identically whether typed (`from:"…"`, `tag:…`, `is:unread`, `has:attachment`) or chosen from the filter menu.
- **New "All" folder** — every folder except junk and trash. Defined once in `core.folder_scope()` so the All *view* (`/email/messages`) and the All search *scope* (`/email/search`) can never disagree about what "all" means.
- `/email/search` now takes an optional `q` (a pills-only search is first-class, ordered by recency), repeatable `labels` (ANDed), `from_addr`/`to_addr`, and the `all` scope.

## Bugs fixed (found in review)
- Load-more and the 20s background refresh silently dropped an active search, swapping ranked hits for a plain folder list and losing the scope. All fetch paths now share one `searchRequest()` builder.
- Pseudo-folders (all/starred) were offered as move-to destinations and as "load older from server" targets, and broke the unread badge. Gated on a shared `isRealFolder()` predicate. (`starred` had these latent too.)
- A second `from:`/`to:` pill left a stale chip that no longer filtered — from/to are now single-valued.
- The expanded search bar could overlap the top-bar actions and swallow their clicks; the actions track now reserves its width.
