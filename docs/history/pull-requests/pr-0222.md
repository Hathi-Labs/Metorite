## Summary

The mobile top app bar was redundant and cost ~44px of vertical space on every mobile screen:

- Its "..." overflow menu (theme toggle, desktop view, sign out) exactly duplicates the bottom Menu drawer's footer
- The static "CommandCenter" title carried no page context

This removes the header from the mobile layout in `AppShell.tsx` while preserving its two real functions:

- **Safe-area inset** — `pt-safe` moves to the mobile shell container, so content stays out of the iPhone notch/status bar
- **Home navigation** — the branding row at the top of the Menu drawer is now a link to `/` (previously the header title was the only way back to the landing page on mobile)

The now-unused `OverflowMenu` component and `MoreHorizontal` import are deleted. Desktop layout is untouched.
