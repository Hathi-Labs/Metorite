What the agent remembers, and for whom

The most consequential setting here. It decides whether one person's private context can reach a transcript the whole room reads.

Memory follows the room, not the person. Facts the agent learns in here land in this room's memory. They reach company-wide memory only when someone explicitly promotes them, and they never land in anyone's personal store. There is no automatic path in the other direction either — personal memory is never pulled into a shared room unless you choose "Driver's context" above.
