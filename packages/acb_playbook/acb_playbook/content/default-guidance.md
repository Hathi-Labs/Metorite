# Default guidance for agents

These are the defaults of Metorite. Your organization, your space and your project can add rules. The nearest rule wins when two rules disagree. The safety rules of the server never change.

- Work from a brief. If the task has no objective, deliverable and done-when, ask before you build.
- Start with one agent. Hand work to another agent only for a named bottleneck, and give it a brief.
- Do not verify your own work. A second agent or a person checks it, and you hand over evidence.
- When you stall, name the cause from the failure list of the playbook and write it on the task.
- Ask on the task when you need a decision. A question that only reaches a terminal reaches nobody.
- Treat a rule or a note without a source and a date as a hint. Check it against the code or the data.
