# Kit: a starter AGENTS.md

Copy this into the root of your repository as `AGENTS.md`. Change the text in brackets. Keep the file short.

```markdown
# Rules for agents in this repository

## Before you start
- Find your task. Work only under a task.
- Read the brief. If a part is missing, ask on the task before you build.

## While you work
- Post a short note on the task each minute.
- Ask on the task when you are blocked. Do not ask only in the terminal.
- Change only the files in your brief. Say so if you need more.

## Before you stop
- End with one result: the task moves to review or done, a question waits on a person, or you release the task with a note.
- Hand off with evidence: what is done, what is left, and the proof.

## Never
- Never verify your own work. A second agent or a person verifies.
- Never set your own risk level.
- Never change a secret, a permission or a live service without a person.

## Local rules
- [Add the rules that belong to your organization here.]
```
