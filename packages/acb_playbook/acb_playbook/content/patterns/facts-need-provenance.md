# Facts need a source and an age

**Use it when** you keep shared notes, rules or lessons that many agents read.

## The pattern

- Give each fact a **source**: the task, the run or the person that produced it.
- Give each fact an **age**: the date someone saw it.
- Give each fact a **check date**. After that date, the fact leaves the active set until someone verifies it again.
- Ask a person to **approve** a fact before other agents read it. An agent may propose. A lead decides.
- Ask the verifier to **re-derive** a fact from the code or the data. The verifier does not copy it from the notes.

## Why

One agent writes a wrong note. Ten agents then read it and act on it. The cost of one wrong fact grows with the number of readers.

## Check yourself

- Can you say where each shared rule came from?
- Which rules are older than your check date?
