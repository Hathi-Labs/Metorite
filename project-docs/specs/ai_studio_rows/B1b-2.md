## What

**The `tools/list` read of the gateway** (task 1152, slice 2 of 3). The gateway reads `tools/list` of each server that the org connected, through `outbound_guard.mcp_client` and `mcp.servers_for_org`, in one new module `gateway/connections/mcp_tools.py`. **The owner of the client is the gateway (WS-STU).** It does not import `orchestrator/_maf_mcp.py`, because a service never imports another service. The catalog GET (`GET /studio/actions`) reads the cache and NEVER calls a server: a cold cache gives the rows of the last read, or none, with `stale: true`. A separate member action refreshes one server (a read of the own org, behind `STUDIO_ORGS`). Dark: `STUDIO_ORGS` is empty on every box, and no test makes a real call (a fake client only). It stores no credential and changes no storage of one (IN-3, task 3176)
