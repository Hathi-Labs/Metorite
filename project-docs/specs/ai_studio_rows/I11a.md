# I11a

Tier: HIGH

Gate: AGENT-SAFE. After B1b-2 and a live MCP read executor. **Traps from the B1b-1 review:** the catalog class is a label, so the class A read must still call the permission gate at run time (a duplicate tool name or a relaxed hint can differ from the label). An `mcp:<server>.<tool>` action must also need `mcp:<server>` in the `connections` of the manifest, so the I1a gate (`STUDIO_CONNECTION_GATE_ORGS`) checks that the member holds that server. B1b-1 does not enforce this, because no executor exists

## What

**The live preview read** (task 3236). The preview reads the class A actions of a connection live, at most 50 rows, with `truncated` set past the cap. The answer carries `live_from`. Flag `STUDIO_LIVE_PREVIEW_ORGS`, default off. A cache keeps the answer for 60 s, keyed by org, member, server, tool and input hash. The place of the cache stays open: in process, or `tenant_redis`. It fails closed for no class, B, C, X and a client error. It changes no credential storage (IN-3, task 3176). It opens no `integration:` source (§8.1 rule 10) and no `as:member` credential (I9). No migration

## Done when

A counting fake client test shows one call for a class A read and none for each other class. An R8 test shows the cache never serves another org or member. The cap and the cache hold
