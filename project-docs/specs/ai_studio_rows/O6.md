Tier: HIGH

Gate: AGENT-SAFE build. **OWNER-GATE** for a live number (STU-Q19)

## What

**Org channel numbers.** An org owns a WhatsApp number that answers outside people. A package claims a number and an entry keyword through the WS-PKG point `channels`. It reuses the webhook split and the SECURITY DEFINER lookup of migration 230

## Done when

A message to an org number reaches the package that claims it, in the right org. Two packages cannot claim the same pair. A member number keeps working as today
