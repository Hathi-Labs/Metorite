# C16

Tier: STD

Gate: AGENT-SAFE. After C13

## What

**Template and run** (task 2346). Wave 1 (D202). A template record makes runs. A run copies the steps and the fields of the template version that it came from, and names that version: a protocol, a checklist, a procedure

## Done when

A run keeps its steps after the template changes. A run names its template version. A run of 30 steps writes in batches of at most 50 writes (C1b)
