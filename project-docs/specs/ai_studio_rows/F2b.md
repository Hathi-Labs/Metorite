## What

🔨 **BUILT, dark (2026-11-02).** **The skill creator UI.** Scope (narrowed, 2026-11-02): one private skill, made, versioned, published, paused and resumed by its owner, over the F2a routes. **Files:** a BFF `workbench/control_plane/src/app/api/studio/[[...path]]/route.ts`, a copy of the workflows proxy for the gateway prefix `/studio`, with PATCH added. It keeps `requireIdentity`, `gatewayHeaders`, `refuseUnsafePath` and `gatewayFetch`, and it adds no header, no identity and no path rule. The Skills section of `app/studio/page.tsx` becomes `components/SkillsGallery.tsx`: a list (name, state badge, version) from `GET /api/studio/skills`, a New skill button, and the present empty state when the list is empty. A 404, a 401 or a network miss keeps the present empty state with no button and no error, because every production org answers 404 until `STUDIO_ORGS` lists it. The routes `app/studio/skills/new/page.tsx` and `app/studio/skills/[id]/page.tsx` share one `SkillForm`. Each page opens with `AppTopBar` and a back link to `/studio`. **The form:** a name (the route makes the slug), one description (it fills `skill.description` and `body.description`), instructions, an action picker, and the buttons Save version, Publish, Pause and Resume. A "describe it" box fills a **no-model starter** (a pure function in `lib/studio/skillStarter.ts` that imports no fetch): `name` from the first 6 words, `description` as "Use this when ...", and `instructions` as a Markdown skeleton with "When to use", "Steps" and "Rules". It fills only empty fields, picks no action, and shows the label "Starting point". **The picker** reads `GET /api/studio/actions` and drops each row with `source == "package"`, because F2a refuses it. It allows class A, B and C, at most 35, no repeat. **Calls:** New skill is `POST /studio/skills` with a `body`. Save version is `POST .../versions`. Publish and Resume send `PATCH .../state {state:"published"}`. Pause sends `{state:"paused"}`. After a Save version on a published skill, the page shows the draft state that the answer returns, and the Publish button returns. **Errors:** a 409 on create shows the text of the store, "You already have a skill with this name. Choose another name.", at the name field. A 422 detail maps by its prefix: `$.actions[i]` to action row i, `$.actions` to the picker, `body.description` and `body.instructions` to their fields, and `name`, `slug` and `description` to theirs. A text with no known prefix shows whole under the form. The page never invents a path. A 409 on a move shows its text under the buttons and reloads the skill. **Non-goals:** a rename or a slug change (F2a has no route), a version list or a diff (F7), archive, share (J2), a test chat or test cases (F4), "Mira drafts" (F2c), skill cards (F5), `SKILL.md` (F8), a chat tool for a skill (F2d), a `gates` entry (the longest prefix `/studio` already gates both routes), and any edit of `studio.json`, `nav.ts` or `gates.generated.ts`. **Preview:** `scripts/dev_up.sh` gives the gateway `STUDIO_ORGS=*` as a fixed local line, with a case in `tests/unit/test_dev_up.py`. No box flips. **Chat parity (rule 15 of the control plane):** the six requests of `lib/studio/skillsApi.ts` are rows of `DEBT` in `chat_parity.py` under wave P-9, and the ceiling of `studio` is 6. F2d pays them and lowers the ceiling.
