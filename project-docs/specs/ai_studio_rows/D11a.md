## What

🔨 **BUILT (2026-11-02).** The page shape in A2. An optional top-level `pages` list: `{id, title?, cols?, tabs?: [{id, title, cells}], cells?, side?: {view}}`, with `cells: [{view, span?}]`. Caps: 8 pages, 8 tabs, 12 cells. Each cell and the side view name a declared view. A page has tabs or cells, not both. The pydantic model of A2 is the one validator. `studio_manifest.schema.json` is regenerated, and `PageDef`, `TabDef`, `CellDef` and `SideDef` join `lib/studio/manifest.ts`. The pure `lib/studio/pageModel.ts` builds the page, and `boundPageState` in `pageState.ts` bounds the URL state (`sel` 64 characters, `tab` a declared id, 8 filters, 200 characters a value, 2,000 characters in all, no prototype key). **Non-goals:** a view-to-node mapper, a new GenUI node type, live data, any block not built, a page editor. `studio_describe` and the G1 skeleton do not mention `pages` yet, so the builder writes none until G3

## Done when

`test_studio_manifest.py` holds the `pages` cases. `test_studio_manifest_ts_parity.py` and the stale-schema test pass. `pageModel.test.ts` and `pageState.test.ts` pass, with a 10,000-filter query, `__proto__` and an unknown tab. The caps in `pageModel.ts` equal the `maxItems` of the schema. A manifest with no `pages` stays valid
