# I7

Tier: HIGH

Gate: AGENT-SAFE. After C11. The cloud APIs after O12

## What

**Biometric device connectors** (task 2404). Later (owner, 2026-11-08), when HR is built (D202.7). The ZKTeco and eSSL ADMS push, to an endpoint for each org with an opaque token in its path. The cloud APIs of eSSL, ZKBioTime and Matrix COSEC go through the OpenAPI import (O12). ADMS carries no signature, so the endpoint takes a push only from a device serial on the list of the org. A serial is no secret, and the row records that risk. It stores punches only, never a biometric template (§19.7)

## Done when

A push from a listed serial writes its punches once. A push from an unknown serial writes nothing and logs the serial. A second delivery of one punch writes no second row (C11). No field type can hold a biometric template
