# B6

Tier: HIGH

Gate: AGENT-SAFE. After H-328

## What

**A run with no viewer.** B6a (below) builds the data, the route and the reads. The rest of this row is not built. An install names one `run_as` member, chosen by an admin. A scheduled or event run holds the rights of that member, cut down to the `uses` of the package. Each write carries `system:package:<id>` and that name (§19.2)

## Done when

A run cannot reach what `run_as` cannot read. A run stops when `run_as` loses access or leaves. The audit row names both
