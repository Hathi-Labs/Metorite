# J7

Tier: HIGH

Gate: AGENT-SAFE. An agent never writes the list of a live org

## What

**The code right for a group, and the code switch of the org** (task 2405). Wave 3, the first code row after L3 (D202.3). Writing code is off by default. An admin turns it on for a group in Studio settings, as a list of D12 grants (`group:<slug>` or an email). It is a Studio setting, not a permission, because the access model gives a permission to a role or a person only (D180.4), and Studio adds no permission past `feature:studio` and `studio:publish` (D180.5). The owner confirmed the label on task 2326 (D202). One admin switch stops all code of the org

## Done when

A member outside the list gets no file tool and cannot save a file. That member still builds with blocks. The switch stops each screen within 10 s, and each server run before it starts
