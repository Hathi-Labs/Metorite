"Pause" means disable and enable (R2). **Non-goals:** the arm or disarm of one trigger (E13c), and J3c. **Pack:** the studio pack is FULL, so these write tools CANNOT join it. A disable has a card only in a held chat, like the F2d pause. **Race rule:** the tool reads the workflow before the card and again after `approved`. It refuses with no write when `status`, `latest_version`, `updated_at` or the triggers changed. It passes the 403, 404 and 409 text on when nothing changed. **Capability:** the tool reads the member capabilities BEFORE the card, from `GET /me` (`routes/admin/me.py`, "effective access"). A member without `workflows:publish` gets no card. **BUILT, dark (2026-11-13, task 3118, PR 2265).** The two tools form the pack `studio-workflows`.
