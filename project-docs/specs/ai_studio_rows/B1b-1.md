## What

**The grammar and the class map of an MCP tool** (task 1152, slice 1 of 3). Source 3 of §3.2. **Pure, no live client, no cache, no migration.** It adds the grammar `mcp:<server>.<tool>` to `_USES_RE`, with `UsesRef.source='mcp'`. It adds one function that turns a tools list that the CALLER passes in into catalog rows. **The one class rule** is the live seam `acb_skills.permission_policy.mcp_needs_confirmation`: a tool is class A when it returns false and its server has no `always_confirm` and no `read_only_key` demand. Any other tool is class B. `destructiveHint` makes no class C, because the seam already counts it as a write (B). §3.2 and §8.1 rule 3 say the same. A row holds the server key, the tool name, the description and the hints, and nothing else of the server. The door refuses an `mcp:` action that the catalog does not list. A preview of an `mcp:` action stays fail closed (`source_not_open`) until I11a. The slice adds one row for the new source to `test_studio_preview_sends_nothing.py` (I11-0), and it extends `test_a_new_source_needs_a_preview_decision`. **Non-goals:** a call to a server, a cache (B1b-2), and the approved description (B1b-3)
