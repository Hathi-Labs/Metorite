# O18

Tier: HIGH

Gate: AGENT-SAFE (D202.8, question 7). After O7, O8 and O9

## What

**Automatic replies to outside people** (task 2422). Wave 2 of §20.8 (D202.8). A level of the trust ladder (D131), with four rules. Rule 1: Mira sends at once only an answer that the approved Knowledge of the org grounds, on a topic that an admin turned on. The reply says that it is automatic, and always offers a person. Rule 2: an answer about the sender's own records needs a sender check, and goes only as a signed link (O4). Rule 3: Mira never answers a clinical question, and staff get a draft. Rule 4: an emergency word gets a fixed safety reply and an alert to the org, with no AI text

## Done when

Each rule has its fence in `tests/unit/test_auto_reply_policy.py`, new with O18: `test_an_auto_reply_needs_a_grounded_answer_on_an_open_topic`, `test_an_own_record_answer_needs_a_sender_check_and_a_link`, `test_a_clinical_question_gets_a_staff_draft_and_no_reply` and `test_an_emergency_word_gets_the_fixed_reply_and_an_alert`
