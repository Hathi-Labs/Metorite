# D24d

Tier: HIGH

Gate: AGENT-SAFE. After D24b. Not built

## What

**The video cap** (task 3347). Wave 1 (D202). After D24b. The server cap for a video is 100 MiB (owner decision, 2026-11-14). D13b stores bytes in a column with a 10 MB check, and a video does not fit it. D24d needs its own storage decision, such as a path column that adds to the table without a rename. The route streams the body to disk. It answers 413 BEFORE it reads the body, when the declared length is over the cap, and it stops a stream that passes the cap. The server makes no duration check. The duration stays a check of the client. **Paths:** the route of D24b. **Non-goals:** a transcode, a frame grab (B13), and the capture UI (lane-ui)

## Done when

A video over 100 MiB gets 413 before the body is read. A stream that grows past the cap stops with 413 and leaves no file. A video under the cap lands in `studio_record_files` of the right org. **Verify:** `uv run pytest tests/unit/test_studio_capture_files.py -q -rs`. The file name is proposed
