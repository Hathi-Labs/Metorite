# D13b-2

Tier: HIGH

Gate: **OPEN.** AGENT-SAFE. With D13c

## What

**The `file` field checks its id against the store.** `studio_fields._file` stays pure (a UUID). The check belongs in the write path of the store: the id must name a `studio_record_files` row of the same org, package, object and field. It lands with D13c, which is the first writer of such a row. Four test files use a file field: `test_studio_fields.py`, `test_studio_row_rules.py`, `test_studio_manifest.py`, `test_studio_field_cases_parity.py`

## Done when

A write that names a file id of another org or record is refused with a sentence
