# B10

Tier: HIGH

Gate: AGENT-SAFE. After D24

## What

**Photo check against a reference** (task 2332). Wave 1 (D202). A first-party action takes a photo and a question, or a reference photo. It answers pass, fail or unsure, with a reason: "Is the label on?" A workflow uses it as a node (E5), and the step player (D14) uses it as a check

## Done when

On a fixed set of 20 test photos, the measured pass rate is at least 90 % (proposed). The owner may set another bar from the result. "Unsure" never counts as a pass. Each call writes one `usage_event` row
