# G1

Tier: STD

Gate: AGENT-SAFE

## What

🔨 **BUILT, dark (2026-11-01).** The builder tools for Mira: draft, patch, validate, outline and list actions. The tools are stateless, because the chat holds the manifest and A3 is Stage 2. A serialized manifest has a cap of 24,000 characters, and each tool result stays under that cap too. Agent `studio-builder` owns the `studio` pack. It is not a second assistant, and Mira alone talks to the member. It never runs as an agent: it is in no agent list (`_PACK_OWNER_AGENTS` in `gateway/routes/agent.py`), and every run refuses a hand-off to it or a run of it (`tool_packs.pack_only_refusal`). Preview waits for G4

## Done when

Each tool refuses an invalid patch with the validator's error, and the manifest stays as it was. No tool runs code. Verify: `uv run pytest tests/unit/test_studio_builder_tools.py tests/unit/test_studio_patch.py tests/unit/test_tool_packs_registry.py -q`
