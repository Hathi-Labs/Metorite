# C23c

Tier: HIGH

Gate: AGENT-SAFE. After C23b

## What

**OPEN (task 3349).** The favourites of each member for a code list: a code that a member marks shows first for that member only. It is member data, so it keeps the identity of the member, never a value from the request

## Done when

A favourite shows first for its member only, and a second member sees none of it
