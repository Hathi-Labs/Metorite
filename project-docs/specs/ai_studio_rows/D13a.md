# D13a

Tier: STD

Gate: AGENT-SAFE

## What

🔨 **BUILT, dark (2026-11-14, task 1421).** The record layout of `render_pdf`. `document_to_pdf` takes `format: "record"`, and `record_source` builds its JSON. The structure is fixed, with no template language: a title, an optional logo, up to 60 label/value pairs, and a lines table of up to 12 columns and 500 rows. The logo is PNG or JPEG, up to 128 KiB and 2048 pixels a side, and the code checks it by magic number and never by name or declared type. GIF, WebP and SVG are refused. The logo sits on page 1 only. The table header repeats on each page. Every label and value is literal text, cut at 2,000 characters, with hidden characters stripped by `strip_hidden`. The code makes no request and logs nothing. A cap breach gives a 413 and a bad logo a 422, both as `PdfRenderError`. No caller, route, action or flag exists yet. Fences: `tests/unit/test_pdf_record_layout.py`, `test_pdf_render.py` and `test_pdf_render_scan.py`

## Done when

One record with a logo and a table of lines gives one PDF. Markup in a value prints as text, and no request leaves the box
