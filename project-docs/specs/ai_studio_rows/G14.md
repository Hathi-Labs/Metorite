# G14

Tier: HIGH

Gate: AGENT-SAFE. After A5

## What

**Clone, export and import an app** (task 2387). Wave 2 (D202). Copy an app inside one org. Export a package version as one file. Import it into another org as a new private draft

## Done when

An import carries no record, no secret and no connection id. An import runs the A2 validator and the catalog check. A clone names its source
