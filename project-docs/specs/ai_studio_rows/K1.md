# K1

Tier: LOW

Gate: AGENT-SAFE

## What

App templates. The store is the code registry `acb_common/studio_templates/`, one plain Studio manifest for each template. It is not a table, and it adds no second manifest shape (D205). U7, U8, U15, U16, U19 and U9 first. D202.5 puts K6, K7 and K8 before them. "One step" means create, publish and the private install of the owner, through the A5 seams (`POST /studio/packages/from-template`, `GET /studio/templates`). 🔨 **BUILT dark, K1a (U7 field visits), 2026-11-11.** It holds the object `visit`, the action `close_visit`, and the board, table, detail and form views. Not built: the calendar view waits on D5, the map view waits on D10 and the paid tile key (STU-Q8), and the `after_visit` workflow and the `tell_customer` action wait. The front door is also BUILT dark (K1a-ui, 2026-11-11): a "Start from a ready app" section in the Studio library (`src/app/studio/components/ReadyApps.tsx`, `src/lib/studio/templatesApi.ts`) lists the templates and installs one with "Use this app". It hides when Studio is off or the list is empty. 🔨 **BUILT dark, K1d, 2026-11-13 (task 2967).** Two chat tools pay the two UI requests of the front door: `studio_template_list` (read) and `studio_create_from_template` (write). The write ALWAYS shows one card first, in a clear chat too, and sends `POST /studio/packages/from-template` only after `approved`. A 409 `package_exists` is a plain answer that names the app. Both sit in `STUDIO_PACKAGE_TOOLS` and in the `studio` family, behind the Studio gate. The `studio` ceiling of `DEBT_CEILING` went from 5 to 3. 🔨 **BUILT dark, K1c, 2026-11-11.** Five more templates: `support-desk` (U8, object `ticket`), `purchase-requests` (U15, object `request`), `expense-claims` (U16, object `claim`), `hiring` (U19, object `candidate`) and `spares` (U9, object `part`). Each holds a board, a table, a detail and a form. Not built in them: the mail and WhatsApp intake, the SLA timers, the approval chains, the receipt reading, the export, the scorecards, the interview calendar, the reorder workflow, and the stat view

## Done when

Each template installs in one step and passes D12. Here "D12" means the manifest conformance fence (`validate_manifest`: no colour, no px size, no credential)
