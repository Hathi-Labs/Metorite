# B9

Tier: HIGH

Gate: AGENT-SAFE. After C21 and D24

## What

**Photo or PDF to fields** (task 2331). Wave 1 (D202). A first-party action reads a photo or a PDF from `attachments`. It proposes values for the fields of a form: a delivery note, a certificate, a nameplate. It reuses the vision path of VOX-3, and each value is a suggestion (C21)

## Done when

A photo of a test delivery note proposes the 5 fields of a test form, each with its reason. Nothing writes until the member accepts a value. A restricted field gets a proposal only when an admin opened it to the AI (D174.6, §19.10 rule 11). Each call writes one `usage_event` row
