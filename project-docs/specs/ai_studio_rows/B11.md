# B11

Tier: HIGH

Gate: AGENT-SAFE. After C21

## What

**Voice into a record** (task 2333). Wave 1 (D202). A member dictates into one field, or speaks a note, and the note fills a whole record, in their own language. It reuses the speech to text of VOX-2. A note for more than one field gives suggestions (C21)

## Done when

A spoken note in Hindi proposes the values of a test form. A dictated field shows its text before the member saves. A restricted field takes no dictation unless an admin opened it to the AI (D174.6). Each call writes one `usage_event` row
