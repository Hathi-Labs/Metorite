## What

🔨 **BUILT, dark (2026-11-07, task 1190).** Edit by diff, with one-step undo, and Publish in the IDE. It lives in the Studio IDE (G3a). Narrowed: a change bar above the editor tabs shows the newest change that landed in the draft in plain words ("You saved: adds the field «Phone» to «Units»", or "Mira or another tab changed the draft: ..."). **Undo** sends the earlier manifest through the one G3c save, with `based_on` = the current hash, and a second press redoes (one step, no history). **Publish** is in the top bar and opens a dialog with the diff of the LIVE version against the draft, then `POST /versions` with `based_on`. New: `GET /studio/packages/{id}/versions/{n}` (the version with its manifest and hash), and `lib/studio/manifestDiff.ts`. A change of order is a change: the diff says "changes the order of the views", and a manifest that differs always gives one line, so Publish never reads "nothing would change" for a real difference. Record actions of one record type fold into one line. Undo is off while edits are unsaved, while a save runs, and when it would drop a live record type or field (a publish makes those, and no member can remove them yet). A new live version clears the change bar. **"Before it applies", as built:** a draft change is not live, so the Publish dialog shows the diff before it applies to the live app. A chat change shows its diff after it lands in the draft, with one-step Undo. The bar sits in the IDE above the tabs, not in the dock, because the dock is the shell's one seam (D89).
