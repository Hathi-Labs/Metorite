## What

**A changed tool shows as changed** (task 1152, slice 3 of 3, the tool-poisoning half). An admin approves the text of a tool (its name, its description and its hints) once. The slice keeps the SHA-256 of the approved text. A tool whose text differs from the approved one shows `changed: true` in the catalog, and it is class B and unavailable to an app or a workflow until an admin approves it again. A new tool is `changed: true` the same way. **The store** is a tenant table with `organization_id` (FORCE RLS, R5), expand only (R6), and a booked migration number (`~/lanes/reserve_migration.sh`, R1). The approval is a member write behind the role that governs the connections of the org (I1), so it is not a role write. A comment records who approved what
