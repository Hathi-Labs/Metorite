# I9

Tier: HIGH

Gate: AGENT-SAFE. After I1

## What

**Whose account** (task 3169). Rung 7 (D220.2). A connection need takes `as` (`org` or `member`) and `scopes`. With `member`, each viewer uses their own connection, and a viewer with none reads nothing. With `org`, the install screen (J6) names the account, and an admin approves it. Mail and calendar default to `member`. A version that widens the scopes asks again (§8.1 rules 3 and 4)

## Done when

R8: a `member` need never reads the connection of another member, in one org and across two orgs. An `org` need with no admin approval runs no action. `test_studio_manifest.py` holds the `as` and `scopes` cases
