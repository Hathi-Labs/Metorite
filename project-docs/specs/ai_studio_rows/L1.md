# L1

Tier: HIGH

Gate: AGENT-SAFE. After L3 passes, L4, G8 and J7. If L3 fails, after SBX-9 and CA-14 (D202.4)

## What

**Custom screens** (§5.4, D202.4). The code block becomes a screen built from the UI kit (L4). The viewer's browser compiles the approved source, and runs it in a locked frame with no network. The server stores source only

## Done when

Code runs with the `--cc-*` tokens only, and every bridge call goes through B2 as the viewer. A version stores source and no bundle that a browser sent. A screen that fails to compile shows its error state, and the page still works
