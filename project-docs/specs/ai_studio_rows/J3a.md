## What

The CHECK of `apps.status` does not change, because a pause is not a status. `packages_store.pause_package(db, actor, id)` locks the `apps` row `FOR UPDATE`. Then it stamps the two columns, and moves each `active` install of the package to `paused` through `package_host/store.pause_install`.
