# O2

Tier: HIGH

Gate: AGENT-SAFE. After O1, A5 and B6

## What

**Surfaces in the manifest:** `surfaces: [{id, kind, view, audience, actions, closes_at?}]`, and the WS-PKG point `surfaces` (one owner for each id). Only an org-scope install holds one, and an admin turns each one on. Each act runs as the install's service identity (B6), limited to the declared actions, and the audit names the surface

## Done when

A guest submits a form and one record lands in state `new`. A guest cannot call an undeclared action. A private or group install with a surface is refused at install. A paused surface answers within 10 s
