## What

🔨 **BUILT, dark (2026-11-01).** The first cut of the invoke door: `POST /studio/apps/{id}/actions/{action}` in `gateway/routes/studio/invoke.py`, on the router of B1. **The order of the checks:** the switch `STUDIO_ORGS` (404 for each body, because the route takes the raw request and FastAPI parses no body first), then the shape of the action (404 for a value that is not an A2 action id), then `packages_store.get_package` for the caller (404 for a package of another member or org, an App Workshop app, or an id that names nothing), then the declared `actions[].id` (403 `not_declared`), then the class (403 `class_x`, or 403 `not_in_catalog` for an id that the catalog does not serve), then 403 `approval_required` for class B and C. A catalog that fails is 503 `catalog_unavailable`. **The one executor** is `object:<name>.get`. It reads the object by its name in the package (`objects_store.get_object_by_name`, new), then the record (`get_record`), each with the package id. The record id is the key `id` of the body, under the id rule of C1. The executor is the only step that parses the body. An object that the package lacks is 404 `object_missing`, and a record id that names nothing is 404 `Not found`. Each other class A action gets 403 `source_not_open`. **The class** of an object action comes from `OBJECT_OP_CLASSES` (§3.2), and the class of each other source from `catalog_rows`. **The audit:** each served or refused call that reaches a package of the caller writes one `app_audit` row (kind `action`) through `routes/apps/_common.record_app_audit_bound`. The row holds the action, its `uses`, its class and the outcome, and no record data. Each text in it has at most 200 characters. A 404 before the package writes no row. The audit is best-effort on purpose, for a class A read only: a failed audit never fails the read. **The org** is the bound session and the member is `user.email`, never request input. **A gap of C1, closed:** `objects_store._PACKAGE_SQL` needs `format = 'manifest'`, so an App Workshop app owns no object. **Not built:** the executors of B2b and the approval of B2c
