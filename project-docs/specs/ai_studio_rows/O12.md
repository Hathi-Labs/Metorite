# O12

Tier: HIGH

Gate: AGENT-SAFE. After I1, I2 and B1b

## What

**Apps over any outside system.** An OpenAPI import grows `custom_api_definitions` into a connection with actions (GET A, other verbs B, DELETE C, an admin may raise a class). Calls go through `outbound_guard.py` with the credentials of `connections/store.py`, a size cap and the untrusted mark (#1444). A remote object (`source: {connection, list, get, create?, update?}`). A mirror into the store, with a cursor and a cap

## Done when

An imported test API gives a list, a detail and a form. A remote object reads through the door as the viewer. A mirror run is idempotent. No call reaches a private address
