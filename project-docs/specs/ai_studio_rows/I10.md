# I10

Tier: STD

Gate: AGENT-SAFE. After I1

## What

**A broken connection is visible** (task 3170). Rung 7 (D220.3). An expired, revoked or removed connection puts each install that needs it in `needs_setup` with one Reconnect card, pauses each trigger with a reason, and makes a skill tell the chat "Reconnect <provider>". The owner of the connection and each app owner get a Needs-you item (§8.1 rule 8)

## Done when

A test revokes a connection. Two installs show the Reconnect card, one trigger reads "Paused: <provider> is not connected", and two Needs-you items exist. A reconnect clears all of them
