# C11

Tier: HIGH

Gate: AGENT-SAFE. After H-328

## What

**Ingest and import.** A CSV into an object with a field map, and a signed endpoint for a device or a vendor push, with a token for each install, a rate limit and a key for each row

## Done when

A second delivery of one punch writes no second row. A wrong signature writes nothing. The endpoint binds the tenant. Rows go in chunks of 50
