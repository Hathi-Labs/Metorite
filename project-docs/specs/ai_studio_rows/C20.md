# C20

Tier: HIGH

Gate: AGENT-SAFE. After A4

## What

**App upgrades that keep the data** (task 2351). Wave 2 (D202). Rename a field, or change its type, on an object that holds records. The publish runs the change in batches, and a failed batch leaves the old version live

## Done when

A rename on 10,000 records keeps every value. A type change that cannot convert a value lists the record and changes nothing. R8
