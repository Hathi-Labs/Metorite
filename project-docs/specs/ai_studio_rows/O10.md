# O10

Tier: HIGH

Gate: AGENT-SAFE in test mode. **OWNER-GATE** for a live account (STU-Q18), and for the first live payment link (D202.8)

## What

**Payments.** The org's own account (Razorpay first) as a row of `integration_connections`. `payments.create_link` (B), `payments.get` (A), `payments.refund` (C, always a card). A signed provider webhook emits `payment.paid` and `payment.failed`. Metorite holds no money and never reuses the Customer Console seam

## Done when

A test-mode link pays and the event moves the record. A forged webhook gives 404. A refund always asks
