# C3

Tier: STD

Gate: AGENT-SAFE

## What

🔨 **BUILT, dark (2026-11-11).** No migration and no route. The action door (`routes/studio/invoke.py`) sets the event when a create, an update or a delete runs. It emits after the session commits, through `studio.preview.emit_record_event`, the one path. The source is `studio`. The types are `studio.record.created`, `studio.record.updated` and `studio.record.deleted`. The payload holds `organization_id`, `package_id`, `object`, `object_id`, `record_id`, `op`, `actor` and `changed` (the keys of the changed fields). It holds no field value, so a restricted field never leaves the store. A refused write, a rolled back write and a preview emit nothing. A sink error never fails the write. **Not built:** an event for a line of a record, and the trigger filter (E3). Since E3-1, `dispatch_event` starts a run for this source with the tenant that the member request bound. It starts one only for an org on `WORKFLOW_UNATTENDED_ORGS`, and that list waits on the owner

## Done when

A write emits one event with the org. A preview emits none. Fence: `tests/unit/test_studio_record_events.py`
