# O9

Tier: HIGH

Gate: AGENT-SAFE build. **OWNER-GATE** for a live send to a real person (CLAUDE.md §3a rule 3), STU-Q17 and STU-Q20

## What

**Sends to outside people** through the Action Broker: a WhatsApp template from an org number, mail from an org sender, SMS. A send that the manifest declares is approved once by an admin at publish (D131). Each other send asks. Every path checks the CRM-M11 suppression list, opt-out and quiet hours

## Done when

A declared confirmation goes to the booking's contact only. A send to anyone else asks. A suppressed contact gets nothing
