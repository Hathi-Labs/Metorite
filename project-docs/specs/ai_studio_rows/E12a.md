# E12a

Tier: HIGH

Gate: AGENT-SAFE. A value of `CORE_EVENTS_ORGS` on a box is `enforcement-flip`

## What

**`people.person.updated`** (source `people`) is emitted from `tasks/people.py::update_person` after the commit, behind `CORE_EVENTS_ORGS` (empty by default). `core_events.py` holds the one emit site, the one reader `core_events_allowed` and the table `EMIT_SITES`. The payload is `person_id`, `actor`, `changed` (the directory-tier keys whose value changed, sorted) and `organization_id`. `update_person` compares each submitted key with the prior row before the UPDATE, so a full form save that changes only skills emits nothing, and a save with no change emits nothing. The dispatcher never reads `organization_id`. The directory tier is `DIRECTORY_FIELDS` in `routes/tasks/people.py`. HR keys, private keys and `clickup_user_id` never appear, and a PATCH of those keys alone emits nothing. One PATCH emits one event, through each of the three doors (`PATCH /tasks/people/{id}`, `PATCH /people/{id}` and `PATCH /people/me`). A sink error never fails the write. The catalog gets one entry in the one served list (`PM_EVENT_TOPICS` is now `EVENT_TOPICS`, with the old name kept as an alias). The `pm.*` entries are unchanged. **Non-goals:** `create_person`, absences, skills, credentials, resume, avatar, calendar, email, WhatsApp and crm. **Privacy choice:** directory-tier keys are org-visible, so the dispatcher needs no author check for `people.*`. A private source (calendar) needs the `_author_may_hear` branch (E3-S, task 3076)

## Done when

**Done when:** `tests/unit/test_core_app_events.py` (no database) maps each catalog event to its emit site both ways and pins the `pm.*` shape. One PATCH through each door emits one event with the org. The payload holds no value. An HR or private change, the flag off and no tenant emit nothing. A raising sink does not fail the write. `tests/unit/test_people_events_r8.py` (R8, in both `--must-run` lists): the event of org A starts only the workflow of org A, no tenant starts nothing, and an empty `CORE_EVENTS_ORGS` starts no run. `test_flag_reload.py` holds the reload. **Verify:** `uv run pytest tests/unit/test_core_app_events.py tests/unit/test_people_events_r8.py tests/unit/test_workflows_triggers_r8.py tests/unit/test_flag_reload.py tests/unit/test_people_profile.py -q -rs`
