Tier: HIGH

Gate: AGENT-SAFE. After O6, H-328 and B6

## What

**Channel events and conversation runs.** `channel.message` on the event bus, with the contact found or created (O5). A conversation run keeps its state for each contact and flow: the step, the values, a timeout

## Done when

Two messages from one phone continue one run. A run that times out ends and says so. Another org's message never reaches the run
