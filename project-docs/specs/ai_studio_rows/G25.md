# G25

Tier: HIGH

Gate: AGENT-SAFE. With L1. The server half after L7

## What

**Build from source only** (task 2398). Wave 3 (D202.10). Metorite accepts source, and never a bundle that a laptop built. Server code builds in a throwaway sandbox (L7), and a screen compiles from the approved source in the browser (L1). The local build serves only the preview and the tests

## Done when

The server refuses a push that holds a compiled bundle, with a fixed code. A version holds source only (§19.10 rule 15). A published server module comes from a build in the sandbox, with its hash in the version
