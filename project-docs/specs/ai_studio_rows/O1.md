# O1

Tier: HIGH

Gate: STU-Q16 (CRM OPEN-1) is decided by D174.1. A live public form still needs the lawyer read of CRM-M11 consent wording (OPEN-3)

## What

**One public door** for every public surface, as CRM-M10 specifies it: an opaque token, a SECURITY DEFINER lookup, then `tenant_session(org)`. Its own host with no cookies. A shared rate limiter in Redis through the prefix wrapper, a bot trap, an optional captcha, size caps, a flat 404. CRM forms and Studio surfaces are its two users. CRM-M10 narrows to "a CRM form on the public door"

## Done when

A post with a valid token reaches one org, and a forged token or another org's token gives a flat 404 and writes nothing. The 11th post in a minute from one address is refused across two gateway processes. The route sets and reads no cookie
