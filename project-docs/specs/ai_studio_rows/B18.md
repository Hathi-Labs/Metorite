## What

**The attendance rule set** (task 2342). Later (owner, 2026-11-08), when HR is built (D202.7). A first-party logic module (B4) with settings: shifts that cross midnight, grace minutes, half days, overtime, holidays and weekly offs. ## Done when

On a fixed test set of punches, each attendance day equals the expected one: a night shift, a late mark inside the grace, a half day, overtime and a holiday. A change of a setting is a new version, and a closed month keeps its version
