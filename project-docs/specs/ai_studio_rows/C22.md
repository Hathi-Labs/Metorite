# C22

Tier: HIGH

Gate: AGENT-SAFE. After C12

## What

**Field library** (task 2353). Wave 2 (task 2327). Shared questions for the whole org, each with its type, units, answers and code mappings. Many forms reuse each question, and a form names the version that it uses. The concept dictionary of OpenMRS is the model

## Done when

Two packages use one library question. A change of it is a new version, and neither form takes it by itself. A package with no access to the library reads nothing of it (C12)
