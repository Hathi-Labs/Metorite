# D13c

Tier: HIGH

Gate: **OPEN.** AGENT-SAFE. After D13b

## What

**The `document.render` action** at the door, class B: it writes a file and sets the `file` field with the caller's viewer. Flag `STUDIO_DOCUMENTS_ORGS`, default off. It reads the logo from the `branding` row of the org settings (migration 234: a data URI up to 128 KiB, checked as PNG, JPEG, GIF or WebP by `acb_common/image_probe.py`). The renderer takes PNG or JPEG only, so a GIF or WebP logo is refused with a sentence. A log line holds ids, sizes and the duration only. This is what "a restricted value stays out of each log" means until C9 exists

## Done when

One record gives one PDF through the door. The flag off gives a refusal. No log line holds a value
