# C9

Tier: HIGH

Gate: AGENT-SAFE

## What

**Field sensitivity** (§19.7). `normal`, `personal`, `restricted`, encryption with a per-org key, an audit row for each read, `[restricted]` in each tool result, and the card path to the viewer

## Done when

The ciphertext is in `data`. A restricted field cannot turn hot or take a filter or an embed. A test runs each chat path and finds no restricted value in what reaches the model. A package with a restricted field and no `access` is refused. A formula or a guard that reads a personal or restricted field makes its target the same level (`rule_reads` of `studio_rules.py`, built in C7a), and a restricted source needs a restricted target
