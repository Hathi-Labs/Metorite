## What

🔨 **BUILT, preview only (2026-11-02).** The Board block on `components/board/`. **Built narrowed: the fake door only.** The block reuses `Board`, `BoardColumn`, `StageChip` and `TaskCardShell` as they are. The drag is native HTML5, as on the other three boards. No Projects code changes, and `src/lib/boards.test.ts` lists the new file. The pure model is `lib/studio/boardModel.ts` (no React import). The view is `components/studio/StudioBoard.tsx`. `bindsSource` in `dataDoor.tsx` gains `board`. **Shape:** `{name: "board", source, data: {fields, groupBy, titleField, cardFields, update, maxCards}}`. `groupBy` must name a select field, or the block shows an error state. A lane holds one option, in the option order. A record with no value or an unknown value goes to a last lane, "No value". `cardFields` holds at most 3 fields, worded by `displayValue` and drawn by `ValueElement`, so no new formatter or chip exists. Each lane shows at most `maxCards` cards (default 50) and a "Show more (n)" line. The count chip shows the true count. **Drag contract:** the card moves at the drop, and exactly one `door.run(update, {id, data: {[groupBy]: option}})` runs. A drop on the same lane calls nothing. A card with a call in flight is locked, so two drops make one call. A refusal puts the card back at its lane and index, and the board shows the door message in a `role="alert"` line through `readRefusal`. A rule refusal names the rule. The keyboard path: Space picks a card up, the arrows choose a lane, Space drops it, Escape cancels, and an `aria-live` line says the result. A "Move to" menu serves touch and 390 px. **Fake door:** `sampleDoor.run` gains a partial update (a patch that lacks a required field), and it refuses a move into "Closed" of a visit that is not done, with the rule `close_needs_done`. **Preview:** a Board section on `/studio/blocks-preview`, on the sample records of the Table. **Out:** order inside a lane, add card, swimlanes, WIP limits, URL state (D11), and the greying of forbidden lanes. The greying waits for the C6 state machine to publish a move table. **Live half:** a drag on a stored object runs on the real door since D3b (below). The block itself is unchanged
