# C24b

Tier: STD

Gate: AGENT-SAFE. After C24a and PKG-8 or E3 with E4

## What

**A critical value raises a need in the bell** (task 2355 holds the pair until a task of its own exists). Wave 2 (task 2327). **OPEN.** It waits on a Studio provider in `routes/shell/needs.py` (PKG-8), or on an E3 trigger with E4. The idempotency key is (org, package, object, record_id, field_key, "critical"). The need stays open while the flag holds, and closes when the value leaves the critical range

## Done when

A critical value raises one need, and a second save of the same value raises no second one
