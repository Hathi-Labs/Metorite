## What

🔨 **BUILT, dark (2026-11-01).** No route, no flag and no UI reach it. Migration `323_studio_objects.sql` copies the two `apps` blocks of 321 (PKG-4) byte for byte, so the two files apply in either order. **The typed object store** (D146.4, §3.1): an object registry, record tables on shared JSONB rows, the field types of §3.1, validation on each write, and an index budget per org. No per-tenant DDL. Expand-only migration, next free number (R1). **Built:** `acb_common/studio_fields.py` holds the field types (16 at C1, 23 since C15a) and the one check of a spec and of a value. A2 imports `FIELD_TYPES` and `validate_field_spec` from it, and A2's `FieldDef` gained `hot`. `gateway/studio/objects_store.py` is the one writer. It holds define, add a field, turn a field hot or cold, and drop for the registry. It holds create, get, update and delete for one record. A read is by id only. Each record function takes a required `package_id`, so a door of one package cannot reach a record of another package. The caller owns the transaction, so C1b can join several calls. **The rules:** a hot field has one of eight types: text, select, number, money, date, datetime, checkbox or email. A hot field takes no `many`. A number is below 10^15 in size, and a value that is not zero is at least 1e-4 in size, because the check refuses a float in exponent form. `v_text` holds the first 256 characters of a text. The options of a select must differ by more than case. A URL holds no user name and no password. A stored field reads with no authoring check, so a stricter rule binds a new spec only. **The lock order:** every write takes the advisory lock of the org first, then the row lock of the object. The org lock is exclusive, so the writes of one org run one at a time. **Hard delete:** A5c-1 deletes a package. It deletes the records in chunks, and then the cascade from `apps` deletes the rest. The App Workshop delete (`routes/apps/lifecycle.py`) cannot reach a package. A5c-1 holds the confirm step: its preview names each object and its record count. **Not built:** no TypeScript twin of the value check. D2 adds it, with a parity test as A2 has
