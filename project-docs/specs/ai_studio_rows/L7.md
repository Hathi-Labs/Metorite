# L7

Tier: HIGH

Gate: AGENT-SAFE. After SBX-9 and B5

## What

**Warm runtimes for server code** (task 2418). Wave 3 (D202). Build once in a throwaway sandbox. Then serve each version from warm runtimes with limits, kept for each org and each version. No runtime serves two orgs. The live pointer moves only after the build and its smoke test pass

## Done when

A failed build leaves the old version live. A runtime of org A never runs a call of org B. A second call of one version starts no new build. An idle runtime stops after its time
