## What

🔨 **BUILT, dark (2026-11-11, task 1202).** **The admin view, in the Studio library.** The pill "All members" in the Apps section of `/studio` shows to a holder of `admin:members:manage` only. `GET /studio/packages?scope=org` is the one read. A holder gets every package of the bound org. Any other caller gets the member list, with `admin: false`, and never a 403. The right is read in `studio/packages_admin_list.py` (`holds_admin_right`), and no new permission exists. The columns and their sources: **package, owner, state and live version** from `apps` (`name`, `owner_email`, `live_version`, where null means draft). **Action calls** from `app_audit` rows with `kind = 'action'` and `detail.action`. A create, a sync and an install write `kind = 'action'` rows with `detail.op`, and they do not count. A "run" today is one call through the door, not a workflow run, so the label says "Action calls". **Last error** is the newest of the last 10,000 `action` rows (with `detail.action`) with outcome `failed` or `refused`: its action id, its outcome and its time, and never the reason text. **Use** is "Not tracked yet", because no package action writes a token, a cost or a `usage_event` row. One set-based statement reads at most 500 packages. The count and the last error read the newest 10,000 action rows of a package. The org list loads after the member list shows, and never holds it. The chat read is `studio_package_get` with `scope` "org" (the same gate, no new tool). **Shared rows come after J2a merges.** "Shared with them" needs `package_host.resolve.visible_installs`, which J2a (PR 2092) adds. No second shared read is built here. Fences: `test_studio_packages_admin_list.py` and `test_studio_packages_admin_list_r8.py` (R8), `packageLibrary.test.ts`. Open: a package card of another member opens nothing, because the package page is the owner's. **After A5c-2 merges (PR 2122),** its scan test must allow `holds_admin_right`, and `packages_admin_list.py` must import its one constant for the right.

## Done when

**Five checks.** (1) A holder gets every package of the bound org, with owner, state, live version, action calls and last error. (2) A member gets only their own. (3) A package of another org never appears. (4) The answer holds no manifest, no reason text and no value. (5) A package with no audit row, or with only the rows of its create and publish, shows "No runs yet", "No errors" and "Not tracked yet"
