# REL-R4

Tier: HIGH

Gate: OWNER-GATE: one answer. Task 3385 holds the question

## What

**The names of a relation to a core object.** A target of the form `<app>.<object>` (for example `crm.company`) gets no entry in `names` in REL-R1. The row needs an owner answer on how a core record is named and who may read it. Task 3385 holds the question.

## Done when

The owner answers the question of task 3385, and this row then names its done condition.
