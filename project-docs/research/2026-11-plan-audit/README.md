These files are research records. They own no work and no status. The board
holds the state of every slice they propose (D118, D190.5).

The owner asked on 2026-11-06 for an audit of the whole plan, and for a plan
for each dark app that Metorite inherited from CommandCenter. The audit report
and the owner's answers are on Metorite task 1958. D190 records the answers.

## How to use these records

1. **Start on the board, not here.** Each slice is a Backlog task under its
   epic. The task holds the acceptance text.
2. **Do not build a slice until the owner orders its plan.** Each plan is
   planning only (D190.4, D190.6).
3. **Check each fact against the code first.** A record describes the code at
   its date: 2026-11-06 and 2026-11-07.
